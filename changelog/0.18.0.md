## Deutsch

Schneller, sparsamer und sauberer: Live-Werte kommen deutlich schneller, die Oberfläche braucht weniger Speicher, ein erster Test am Audi A2 ist vorbereitet, und alles rund um Lizenzen, Sicherheit und Updates ist aufgeräumt.

**Schneller und sparsamer**
- Live-Werte: eine Runde mit sechs Werten dauert an einem ELM327 etwa halb so lange, es kommen rund dreimal so viele Werte pro Sekunde an
- Verbinden geht schneller, das Demo-Auto ist fast sofort da
- Die Oberfläche startet mit einem kleineren Paket, zeichnet Live-Werte höchstens einmal pro Bild und gar nicht auf versteckten Seiten; der Speicher wächst bei langen Sitzungen kaum noch
- Die Röntgenansicht gibt Grafikspeicher sauber frei und pausiert im Hintergrund

**Audi A2 und andere VW-Gruppe-Autos mit K-Line**
- Neue Seite "Erster Test am Auto" für das KKL-Kabel: Kabeltest ohne Auto (Chip, Latenz-Timer), genaue Zeiten der Weckadresse mit klarer Ursache, wenn etwas nicht klappt, dann Schritt für Schritt Motor, Kombiinstrument, ABS, Airbag, Komfort und Zentralelektrik, nur lesend, am Ende ein Testbericht zum Speichern
- Behoben: Beim Lesen eines Anpassungskanals wurde der Befehl für "Speichern" gesendet statt für "Lesen"

**Updates**
- Caruspex fragt jetzt einmal, ob es nach Updates suchen soll; ohne Ja geht keine Anfrage an GitHub
- Mit Ja sucht es beim Start und alle sechs Stunden, eine neue Version zeigt nur einen Knopf in der Titelleiste
- Kopien, die nie installiert wurden, können sich jetzt auch aktualisieren: der signierte Setup kommt von GitHub
- Eine Aktualisierung wird nur angenommen, wenn die Signatur genau zu dieser Datei und Version gehört

**Lizenzen, Sicherheit und Datenschutz**
- Alle Lizenzen der verwendeten Bausteine liegen jedem Paket bei und lassen sich in den Einstellungen ansehen
- Hinweise zu Sicherheit, Haftung und Marken in der README, der Anleitung und der App
- Zu jedem Release gibt es eine Stückliste (SBOM), Prüfsummen und einen Herkunftsnachweis des Builds
- Eine beschädigte Garage-Datei wird nicht mehr überschrieben, sondern als Kopie aufgehoben

Hinweis: Der erste Test am A2 ist nur mit einem nachgebildeten Auto geprüft, noch nicht an einem echten.

## English

Faster, leaner and cleaner: live values arrive much faster, the interface needs less memory, a first test on the Audi A2 is ready, and everything around licences, security and updates is tidied up.

**Faster and leaner**
- Live values: a round of six values takes about half as long on an ELM327, about three times as many values per second arrive
- Connecting is faster, the demo car is there almost at once
- The interface starts with a smaller bundle, draws live values at most once per frame and not at all on hidden pages; memory barely grows in long sessions
- The X-ray view frees graphics memory properly and pauses in the background

**Audi A2 and other VW group cars with a K-line**
- New page "First test on the car" for the KKL cable: a cable test without the car (chip, latency timer), the exact timing of the wake-up with a clear reason when something fails, then step by step engine, instrument cluster, ABS, airbag, comfort and central electrics, read only, ending with a test report to save
- Fixed: reading an adaptation channel sent the command for "save" instead of "read"

**Updates**
- Caruspex now asks once whether to look for updates; without a yes no request goes to GitHub
- With a yes it looks at start and every six hours, a new version only shows a button in the title bar
- Copies that were never installed can now update too: the signed setup comes from GitHub
- An update is only accepted when its signature belongs to exactly this file and version

**Licences, security and privacy**
- All licences of the components used ship with every package and can be viewed in the settings
- Safety, liability and trademark notes in the README, the guide and the app
- Every release comes with a bill of materials (SBOM), checksums and a build provenance attestation
- A damaged garage file is no longer overwritten but kept as a copy

Note: the first test on the A2 has only been tested with a simulated car, not yet on a real one.
