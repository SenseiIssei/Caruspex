## Deutsch

Neu gebaut: Caruspex ist jetzt in Rust geschrieben und hat eine neue Oberfläche. Alles, was 0.8 konnte, kann auch diese Version, mit denselben Ergebnissen am Auto.

**Neue Grundlage**
- Der Kern ist neu in Rust geschrieben, in kleinen Bausteinen für Adapter, Protokolle, Fahrzeugdaten und Auswertungen. Die Oberfläche läuft mit Tauri, das Programm ist dadurch kleiner und startet schneller
- Rund 390 automatische Tests prüfen jede Verbindungsart und jedes Protokoll gegen nachgebaute Steuergeräte, das Demo-Auto und Vergleichsdaten aus Version 0.8
- Garage, Einstellungen und Aufzeichnungen aus 0.8 werden übernommen. Der Windows-Installer aktualisiert eine vorhandene Installation an Ort und Stelle und räumt die alten Dateien weg

**Oberfläche**
- Alle Seiten neu gezeichnet, mit ruhigeren Übergängen, schärferen Symbolen und einem Durchsicht-Auto, das zeigt, wo ein Fehler sitzt
- Die Seitenleiste passt wieder ganz ins Fenster
- In der Titelleiste erscheint ein Hinweis, sobald eine neue Version da ist. Dafür fragt Caruspex beim Start nur GitHub nach der neuesten Version, sonst nichts; in den Einstellungen lässt sich das abschalten
- Der Prüfbericht wird unter Windows direkt als PDF gespeichert

**Verbindungen**
- Klassisches Bluetooth geht unter Windows und Linux jetzt direkt, ohne den Umweg über einen COM-Anschluss
- Beim Fehlerspeicher unterscheidet der Gesundheitscheck wieder, ob nichts gelesen werden konnte oder ob wirklich keine Fehler da sind
- An Bluetooth-Geräte, die nicht eindeutig ein OBD-Adapter sind, sendet Caruspex gar nichts mehr

**Sprachen**
- Die Hinweise im Fahrzeugkatalog sind jetzt in allen 18 Sprachen übersetzt, bisher standen sie dort auf Englisch
- Die Beschreibung auf GitHub gibt es in allen 18 Sprachen

**Pakete**
- Für Linux gibt es zusätzlich ein .deb-Paket, die Kommandozeile caruspex_cli gibt es für alle drei Systeme

Hinweis: Unter macOS und Linux öffnet der Prüfbericht noch den Druckdialog, statt das PDF direkt zu speichern. Mit echter Hardware ist diese Version noch nicht geprüft, nur mit nachgebauten Geräten und dem Demo-Auto. Die Pakete sind weiterhin nicht signiert.

## English

Rebuilt: Caruspex is now written in Rust and has a new interface. Everything 0.8 could do, this version can do too, with the same results at the car.

**New foundation**
- The core is rewritten in Rust, in small building blocks for adapters, protocols, vehicle data and analysis. The interface runs on Tauri, which makes the program smaller and quicker to start
- About 390 automatic tests check every connection type and every protocol against simulated control units, the demo car and reference data from version 0.8
- Garage, settings and recordings from 0.8 carry over. The Windows installer updates an existing installation in place and removes the old files

**Interface**
- Every page redrawn, with calmer transitions, sharper icons and a see-through car that shows where a fault sits
- The sidebar fits into the window again
- A notice appears in the title bar as soon as a new version is out. For this Caruspex only asks GitHub for the newest version at start, nothing else; it can be switched off in the settings
- On Windows the report is saved straight as a PDF

**Connections**
- Classic Bluetooth now works directly on Windows and Linux, without the detour through a COM port
- For the fault memory the health check again tells apart "could not be read" from "really no faults"
- Caruspex sends nothing at all to Bluetooth devices that are not clearly an OBD adapter

**Languages**
- The notes in the vehicle catalogue are now translated into all 18 languages; until now they showed in English there
- The description on GitHub is available in all 18 languages

**Packages**
- Linux also gets a .deb package, and the caruspex_cli command line tool comes for all three systems

Note: on macOS and Linux the report still opens the print dialog instead of saving the PDF directly. This version has not been tested with real hardware yet, only with simulated devices and the demo car. The packages are still not signed.
