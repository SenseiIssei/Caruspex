# Kvaser (Windows)

Kvaser के CAN एडैप्टर (Leaf, U100, Memorator और दूसरे) Windows पर सीधे Kvaser की लाइब्रेरी CANlib के ज़रिए इस्तेमाल किए जा सकते हैं। Linux पर ये [SocketCAN](socketcan.md) इंटरफ़ेस हैं।

## कनेक्ट करना

1. Kvaser ड्राइवर इंस्टॉल करें। इनके साथ `canlib32.dll` आती है, जिसे Caruspex लोड करता है।
2. **जुड़ें** पेज पर **CAN इंटरफ़ेस** चुनें। जिस भी Kvaser चैनल के पीछे डिवाइस है, वह सूची में दिखता है; ड्राइवर के वर्चुअल चैनल छोड़ दिए जाते हैं।
3. बिट रेट चुनें (CAN पर OBD के लिए 500 kbit/s) और कनेक्ट करें।

## क्या काम करता है

OBD, UDS से हर कंट्रोल यूनिट, कंट्रोल यूनिट की पैरेलल खोज, VW TP 2.0 और ब्रॉडकास्ट वैल्यू सुनना। CANlib पर CAN FD अभी नहीं जोड़ा गया है।

## कमांड लाइन

```
caruspex_cli read --can kvaser:0@500000
```
