# USB से ELM327

OBD सॉकेट के लिए एक प्लग, जिसकी केबल USB पोर्ट तक जाती है। यह ELM327 का सबसे भरोसेमंद रूप है: न पेयरिंग, न रेडियो, न ख़त्म बैटरी।

## ड्राइवर

प्लग के अंदर एक USB चिप केबल को सीरियल पोर्ट (Windows पर COM पोर्ट) में बदलती है। कौन सा ड्राइवर चाहिए, यह उस चिप पर निर्भर करता है:

| चिप | ड्राइवर |
|---|---|
| FTDI FT232 | आमतौर पर Windows ख़ुद इंस्टॉल करता है, Linux और macOS में पहले से मौजूद |
| CH340 / CH341 | आमतौर पर Windows ख़ुद इंस्टॉल करता है, Linux और macOS में पहले से मौजूद |
| Silicon Labs CP210x | अगर Windows न ढूँढ पाए तो निर्माता की वेबसाइट से |
| Prolific PL2303 | निर्माता की वेबसाइट से; पुराने क्लोन अक्सर सिर्फ़ पुराने ड्राइवर के साथ चलते हैं |

लगाने के बाद Windows का डिवाइस मैनेजर एडैप्टर को "Ports (COM & LPT)" के नीचे दिखाता है।

## कनेक्ट करना

1. एडैप्टर को गाड़ी में लगाएँ, इग्निशन ऑन करें, केबल को कंप्यूटर में लगाएँ।
2. **जुड़ें** पेज पर **USB या COM पोर्ट** चुनें।
3. पोर्ट को **अपने आप खोजें** पर रहने दें या सूची से चुनें, फिर कनेक्ट करें।

ऑटोमैटिक खोज हर सीरियल पोर्ट को आम स्पीड पर आज़माती है। अगर आप अपने एडैप्टर की स्पीड जानते हैं, तो उसे सेटिंग्स में **एडैप्टर बॉड रेट** के तहत सेट कर सकते हैं।

## Linux और macOS

Linux पर एडैप्टर `/dev/ttyUSB0` या `/dev/ttyACM0` के रूप में दिखता है। आपका यूज़र `dialout` ग्रुप में होना चाहिए ([इंस्टॉल करना](install.md) देखें)। macOS पर यह `/dev/cu.usbserial-...` या `/dev/cu.wchusbserial...` के रूप में दिखता है।

## आम दिक्कतें

- **कोई पोर्ट नहीं दिखता**: ड्राइवर नहीं है या केबल सिर्फ़ चार्जिंग वाली है।
- **एडैप्टर जवाब देता है, गाड़ी नहीं**: इग्निशन ऑफ़ है, या एडैप्टर ऐसा क्लोन है जो गाड़ी का प्रोटोकॉल नहीं संभालता। [एडैप्टर टेस्ट](interfaces.md) आपको ज़्यादा बताएगा।
- **पुरानी गाड़ियों पर बहुत धीमी लाइव वैल्यू**: K-Line ख़ुद धीमी है, इसमें एडैप्टर की ग़लती नहीं है।
