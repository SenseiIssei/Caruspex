# इंस्टॉल करना

हर रिलीज़ [GitHub के रिलीज़ पेज](https://github.com/SenseiIssei/Caruspex/releases/latest) पर है। पैकेज अभी साइन नहीं किए गए हैं, इसलिए Windows और macOS पहली बार चलाने से पहले एक बार पूछते हैं।

## Windows 10 और 11

| फ़ाइल | यह क्या है |
|---|---|
| `Caruspex-<version>-windows-x64-setup.exe` | इंस्टॉलर। इसे एडमिन अधिकार नहीं चाहिए, यह कमांड-लाइन टूल `caruspex_cli` को सर्च पाथ में डाल सकता है और WebView2 रनटाइम सिर्फ़ तभी इंस्टॉल करता है जब वह मौजूद न हो। |
| `Caruspex-<version>-windows-x64.zip` | पोर्टेबल: अनज़िप करें और `caruspex.exe` चलाएँ। |

पहली बार चलाने पर Windows SmartScreen कह सकता है कि ऐप अनजान है: "More info" पर क्लिक करें, फिर "Run anyway" पर।

USB एडैप्टरों को उनकी USB चिप के लिए ड्राइवर चाहिए। Windows 10 और 11 आमतौर पर उसे ख़ुद ढूँढ लेते हैं; अगर नहीं, तो [USB से ELM327](elm327-usb.md) देखें।

## macOS 13 और नया (Apple Silicon)

`Caruspex-<version>-macos.dmg` डाउनलोड करें, उसे खोलें और Caruspex को Applications में खींचें। क्योंकि ऐप अभी नोटराइज़ नहीं हुआ है, पहली बार इसे राइट क्लिक और "Open" से खोलें।

## Linux (x86_64)

| फ़ाइल | यह क्या है |
|---|---|
| `Caruspex-<version>-linux-x86_64.AppImage` | लगभग हर डिस्ट्रीब्यूशन पर चलता है: `chmod +x` से इसे एक्ज़िक्यूटेबल बनाएँ और चलाएँ। यह ख़ुद को अपडेट भी करता है। |
| `Caruspex-<version>-linux-amd64.deb` | Debian और Ubuntu के लिए: `sudo apt install ./Caruspex-<version>-linux-amd64.deb` |

सीरियल एडैप्टरों को `sudo` के बिना इस्तेमाल करने के लिए, एक बार ख़ुद को `dialout` ग्रुप में जोड़ें, फिर लॉग आउट करके दोबारा लॉग इन करें:

```
sudo usermod -aG dialout $USER
```

## सिर्फ़ कमांड-लाइन टूल

स्क्रिप्ट और सर्वर के लिए बिना इंटरफ़ेस वाला `caruspex_cli` है, Windows, Linux और macOS के लिए। `caruspex_cli help` कमांडों की सूची दिखाता है।

`caruspex_cli report` ऐप के बिना डायग्नोस्टिक रिपोर्ट को PDF फ़ाइल में लिखता है, और बाकी कमांड जो भी कनेक्शन जानते हैं, उन सब से काम करता है (`--demo`, `--port`, `--tcp`, `--enet`, `--can`, `--replay`):

```
caruspex_cli report --demo report.pdf
caruspex_cli report --port COM5 --lang de report.pdf
```

रिपोर्ट जर्मन, अंग्रेज़ी, स्पैनिश, फ़्रेंच, पुर्तगाली, इतालवी, डच और इंडोनेशियाई में बन सकती है (`--lang`)। हिंदी समेत बाकी भाषाओं में यह अंग्रेज़ी में बनती है, क्योंकि हर PDF व्यूअर में पहले से मौजूद फ़ॉन्ट में उनके अक्षर नहीं होते।

## अपडेट

हर इंस्टॉलेशन पर Caruspex एक बार पूछता है कि क्या वह अपडेट खोजे। केवल "हाँ" के बाद ही वह GitHub से पूछता है कि कोई नया वर्शन है या नहीं, और इसके अलावा कुछ नहीं। नया वर्शन तभी इंस्टॉल होता है जब उसका सिग्नेचर ऐप में बनी कुंजी से मेल खाए। जाँच और ऑटोमैटिक इंस्टॉलेशन, दोनों सेटिंग्स में कभी भी बदले जा सकते हैं।

## पैकेज मैनेजर

winget, Homebrew, Flathub और Snap के पैकेज तैयार हो रहे हैं। जब तक वे प्रकाशित नहीं होते, ऊपर की फ़ाइलें ही Caruspex इंस्टॉल करने का तरीका हैं।
