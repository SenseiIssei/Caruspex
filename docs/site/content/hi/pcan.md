# PEAK PCAN (Windows)

PEAK-System के CAN एडैप्टर (PCAN-USB, PCAN-USB FD, PCAN-USB Pro और दूसरे) Windows पर सीधे, बिना J2534 ड्राइवर के इस्तेमाल किए जा सकते हैं। Linux पर ये [SocketCAN](socketcan.md) इंटरफ़ेस हैं।

## कनेक्ट करना

1. PEAK का डिवाइस ड्राइवर इंस्टॉल करें। इसके साथ लाइब्रेरी `PCANBasic.dll` आती है, जिसे Caruspex लोड करता है।
2. **जुड़ें** पेज पर **CAN इंटरफ़ेस** चुनें। जिस भी PCAN चैनल के पीछे डिवाइस है, वह अपने आप सूची में दिखता है; जो चैनल पहले से किसी दूसरे प्रोग्राम के इस्तेमाल में हैं, वे छोड़ दिए जाते हैं।
3. बिट रेट चुनें (CAN पर OBD के लिए 500 kbit/s) और कनेक्ट करें।

## क्या काम करता है

OBD, UDS से हर कंट्रोल यूनिट, कंट्रोल यूनिट की पैरेलल खोज, VW TP 2.0 और ब्रॉडकास्ट वैल्यू सुनना। PCAN-Basic पर CAN FD अभी नहीं जोड़ा गया है।

## कमांड लाइन

```
caruspex_cli read --can pcan:USB1@500000
```
