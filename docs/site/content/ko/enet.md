# BMW ENET 케이블

F 시리즈부터(대략 2008년 이후)의 BMW와 Mini는 OBD 단자에 이더넷이 있어요. ENET 케이블은 OBD 단자에서 컴퓨터의 랜 포트로 바로 연결되고, 중간에 어댑터 칩이 없어요. Caruspex는 차의 게이트웨이와 HSFZ로 통신하고(포트 6811과 6801), 모든 제어 장치에 접속해요.

## 연결하기

1. 케이블을 차와 컴퓨터의 랜 포트(또는 USB 랜 어댑터)에 꽂아요. 점화 스위치를 켜요.
2. 최대 1분 기다려요: DHCP 서버가 없으면 Windows, macOS, Linux가 알아서 컴퓨터에 자동 주소(169.254.x.x)를 줘요.
3. **연결** 페이지에서 **네트워크 케이블**을 고르고 입력란은 비워 둬요: Caruspex가 네트워크에서 차를 찾아요. 검색으로 아무것도 찾지 못하면 차의 주소를 입력해요.

## 되는 것

- BMW 주소 방식의 UDS로 모든 제어 장치에 접속, 고장 코드는 ISTA처럼 BMW 형식으로 표시(예: 480A10).
- 제어 장치별 고장 메모리, 식별 정보, 삭제, OBD를 통한 실시간 값.
- 여기서도 Caruspex는 읽기만 해요. 코딩과 플래싱은 정비소용 프로그램의 몫이에요.

## 어떤 케이블?

일반 ENET 케이블에는 8번과 16번 핀 사이에 저항이 있어서 차의 이더넷을 켜 줘요. 저항이 없는 케이블로는 차가 반응하지 않아요. 1 Gbit/s 랜 포트도 쓸 수 있고, 차는 100 Mbit/s로 통신해요.

## 명령줄

```
caruspex_cli ecus --enet auto
```
