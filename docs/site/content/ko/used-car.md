# 중고차 점검

차를 사기 전에 보러 갈 때 쓰는 기능이에요. 노트북과 어댑터를 가져가서 꽂으면, **중고차** 페이지가 판매자가 쉽게 숨길 수 없는 것들을 점검해요.

![중고차 점검](screenshot-used-car.png)

## 점검하는 것

- **VIN**: 제어 장치 안의 VIN이 자동차 등록증과 카탈로그의 VIN과 일치하나요?
- **주행 거리**: 여러 제어 장치의 주행 거리 기록이 서로 맞나요?
- **최근에 지웠나요?** 고장 메모리를 마지막으로 지운 뒤의 주행 거리와 시간. 차를 보러 가기 직전에 지웠다면 경고 신호예요.
- **준비 상태 모니터**: 모두 완료됐나요, 아니면 초기화됐나요?
- **저장된 고장**과 **상태 점검**.
- 전기차라면 **배터리 상태**(배터리 수명 상태, 셀). 차가 보고하는 경우에요.

## 결과

신호등 표시, 판매자에게 물어볼 질문, 그리고 구매용 PDF.

## 알아 두면 좋은 것

- 점화 스위치를 켜요. 시동이 걸려 있어도 돼요. 엔진이 차가우면 일부 테스트는 미완료로 남아요.
- 깨끗한 결과가 보증은 아니에요: OBD는 전자 장치를 보는 것이지 녹, 사고 손상, 기계 마모는 보지 못해요. 정비소에서도 차를 봐 달라고 하세요.
- 무엇이든 꽂기 전에 판매자에게 먼저 물어보세요.
