# Wi-Fi로 연결하는 ELM327

어떤 어댑터는 자체 Wi-Fi 네트워크를 열어요. 컴퓨터가 그 네트워크에 접속해서 TCP로 어댑터와 통신해요.

## 연결하기

1. 어댑터를 꽂고 점화 스위치를 켜요. 몇 초 뒤에 Wi-Fi 네트워크가 나타나는데, 이름은 주로 `WiFi_OBDII`, `V-LINK` 또는 제조사 이름이에요.
2. 컴퓨터로 그 네트워크에 접속해요. 인터넷이 없기 때문에 시스템이 연결이 제한되었다고 경고할 수 있는데, 괜찮아요.
3. Caruspex의 **연결** 페이지에서 **Wi-Fi**를 골라요. 대부분의 어댑터는 주소 `192.168.0.10`과 포트 `35000`을 쓰고, 이 값이 미리 설정되어 있어요. 내 어댑터가 다른 주소(예: `192.168.4.1`)를 쓴다면 `address:port` 형식으로 입력해요.

## 팁

- 컴퓨터가 어댑터의 네트워크에 있는 동안에는 인터넷을 쓸 수 없어요. Caruspex에는 상관없어요.
- Wi-Fi 어댑터는 어떤 시스템에서도 드라이버 없이 작동해요.
- 연결이 끊기면 컴퓨터를 차에 더 가까이 두세요: 이런 플러그는 무선 신호가 약해요.
