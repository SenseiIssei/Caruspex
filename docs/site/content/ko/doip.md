# DoIP (Diagnostics over IP)

2016년경 이후의 많은 차는 ISO 13400에 따라 이더넷으로 진단할 수 있는데, 이것을 DoIP라고 해요. DoIP 케이블은 OBD 단자와 컴퓨터의 랜 포트를 연결해요.

## 연결하기

1. 케이블을 꽂고 점화 스위치를 켠 다음, 컴퓨터가 자동 주소(169.254.x.x)를 받을 때까지 기다려요. 최대 1분 정도 걸릴 수 있어요.
2. **연결** 페이지에서 **네트워크 케이블**을 고르고 입력란은 비워 둬요. Caruspex가 네트워크에서 DoIP 차량을 찾고, 그 차가 DoIP를 쓰는지 BMW의 HSFZ를 쓰는지 스스로 알아내요.

## 되는 것

DoIP를 통한 OBD, 그리고 Caruspex가 해당 브랜드의 주소를 알고 있는 제어 장치에 대한 UDS 접속. DoIP 차량의 주소 목록은 아직 짧아요. 실제 차의 기록이 이 목록을 채워 나가요(공유한 기록에 무엇이 들어 있는지는 [개인정보](privacy.md) 참고).

## 어떤 케이블?

DoIP에는 OBD 단자 3, 11, 12, 13번 핀의 이더넷 선과 8번 핀의 활성화 선이 필요해요. 특정 브랜드용으로 판매되는 케이블은 보통 정확히 그렇게 배선되어 있고, BMW ENET 케이블도 그중 하나예요.

## 명령줄

```
caruspex_cli enet
```

네트워크에서 찾은 BMW와 DoIP 차량을 보여 줘요.
