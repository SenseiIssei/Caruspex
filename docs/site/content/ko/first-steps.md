# 첫걸음

## 1. 데모 차량 써 보기

둘러보는 데는 차가 필요 없어요. **연결** 페이지에서 **데모 차량**을 고르세요: 달리고, 예열되고, 고장이 몇 개 저장되어 있고, 진짜 ELM327처럼 응답해요. 모든 페이지가 데모 차량으로 작동해요.

## 2. 언어와 모드 고르기

Caruspex는 시스템 언어를 따라가요. **설정**에서 18개 언어 중 하나와 밝은 화면 또는 어두운 화면을 고를 수 있고, 둘 다 다음 실행 때 바뀌어요.

**초보자 모드**는 일상적으로 쓰는 페이지를 보여 줘요. **전문가 모드**는 정비소용 도구를 더해요: KKL 페이지, 적응, 어댑터 원시 명령, 제어 장치 주소.

## 3. 내 차 연결하기

1. 진단 단자를 찾아요: [연결 도우미](connect.md)가 내 차에서 단자가 어디 있는지 보여 줘요.
2. 어댑터를 꽂고 점화 스위치를 켜요. 시동이 걸려 있어도 되지만, 꼭 그럴 필요는 없어요.
3. **연결** 페이지에서 연결 방식을 고르거나, Caruspex가 모든 포트를 스스로 찾게 해요.

처음 실행할 때 연결 도우미가 저절로 열려요. 모든 단계는 건너뛸 수 있고, 도우미는 설정과 연결 페이지에서 다시 열 수 있어요.

![연결 페이지](screenshot-connect.png)

## 4. 차를 처음 살펴보기

연결하면 Caruspex가 VIN을 읽고 어떤 차인지 알려 줘요. 시작하기 좋은 곳:

- **상태 점검**: 버튼 하나, 30초 정도, 0부터 100까지 점수가 나오고 깎인 점수마다 이유를 설명해요.
- **지금 무엇을 해야 할까요?**: 찾은 모든 것을 세 단계로 나눠서 보여 줘요.
- [고장 메모리](faults.md)와 [실시간 값](live.md).

![상태 점검](screenshot-health.png)

## 5. 차고와 보고서

모든 차는 VIN으로 구별되고, 차고에 자기 항목이 생겨서 점검 기록과 주행 거리 기록이 남아요. 점검 보고서는 정비소에 가져갈 수 있게 PDF로 저장할 수 있어요.
