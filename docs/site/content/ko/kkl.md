# KKL 케이블 (VAG 409.1)

KKL 케이블은 시리얼 칩과 K-Line 드라이버가 들어 있는 USB 케이블이고, 안에 ELM327은 없어요. Caruspex가 K-Line을 바이트 단위로 직접 다뤄요. 오래된 VW, Audi, Seat, Skoda에 필요한 게 바로 이거예요: 이 차들의 프로토콜 KWP1281은 바이트 하나하나를 확인 응답하는데, 어떤 ELM327도 그렇게 하지 못해요.

## 되는 것

- 1990년부터 2004년경까지의 VW, Audi, Seat, Skoda의 모든 제어 장치: 엔진, 변속기, ABS, 에어백, 계기판, 편의 장치 등.
- KWP1281과 KWP2000 (ISO 14230), 웨이크업 후 키 바이트로 자동 판별.
- 제어 장치별 고장 메모리, 측정 블록, 그리고 스로틀 바디의 진짜 기본 설정(측정 블록 060 또는 098).
- 적응 채널은 일부러 읽기 전용으로 두었어요. 출력 테스트는 실제 부품을 작동시키므로 확인한 뒤에만 시작해요.

이 페이지들은 **전문가 모드**에 있어요: **KKL 경유 제어 장치**, **스로틀 바디**, **적응 및 출력 시험**. 각 페이지가 케이블을 직접 열어요: 시리얼 포트와 제어 장치를 고르고 시작하면 돼요.

## 어떤 케이블?

정품 FTDI FT232RL이나 CP2102가 들어간 케이블은 가장 싼 복제품보다 K-Line에서 훨씬 믿을 만해요. KWP1281에는 정품 FTDI를 추천해요. 케이블은 K-Line을 가공 없이 그대로 통과시켜야 해요: 자체 펌웨어가 있는 "HEX-USB" 인터페이스는 작동하지 않아요.

1996년경 이전의 차에는 OBD 단자가 없고, 엔진룸이나 대시보드 아래에 2x2 플러그가 있는 경우가 많아요. 2x2를 16핀 단자로 바꾸는 어댑터는 저렴해요.

## 케이블 점검

명령줄 도구로 차 없이 케이블을 테스트할 수 있어요:

```
caruspex_cli kklcheck --port COM3
```

## 실차 첫 테스트

전문가 모드 페이지 **실차 첫 테스트**는 새 KKL 케이블로 하는 첫 세션을 안내해요. Audi A2에 맞춰져 있고, K-Line이 있는 VW, Audi, Seat, Skoda라면 어느 차에서나 돼요. 읽기만 해요: 아무것도 삭제하지 않고, 출력 시험도 기본 설정도 하지 않아요. 포트는 테스트를 시작할 때만 열려요.

1. **차 없이 케이블을 점검하세요.** 케이블을 USB에만 꽂고, 그 포트를 고른 뒤 **케이블 점검**을 누르세요. Caruspex가 칩(FTDI, CH340, Prolific, CP210x)과, FTDI라면 지연 타이머를 읽고, Break 라인에서 5 baud 주소의 비트를 측정해요. 차 없이는 에코가 돌아오지 않는데, 그게 정상이에요.
2. **지연 타이머를 1 ms로 설정하세요**(Windows의 FTDI 케이블): 장치 관리자, 포트(COM & LPT), USB Serial Port 두 번 클릭, 포트 설정, 고급, Latency Timer (msec)를 1로, OK, 그다음 케이블을 한 번 뽑았다가 다시 꽂으세요. 기본값 16 ms에서는 키 바이트 응답이 50 ms 창을 놓칠 수 있어요. Caruspex는 이 설정을 읽기만 하고 절대 바꾸지 않아요.
3. **차에서:** 시동 스위치 켜고 엔진은 끈 상태, 케이블은 OBD 단자에 단단히 꽂고 컴퓨터에 직접 연결(USB 허브 없이), 다른 진단 프로그램은 닫아 두세요. 체크리스트를 모두 체크하고 **첫 테스트 시작**을 누르세요.
4. 테스트는 엔진(주소 01)을 깨우고 주소의 모든 비트, 동기 바이트 0x55, 키 바이트와 그 응답을 측정해요. 그다음 식별 정보, 고장 메모리, 측정 블록 001부터 003까지를 읽고, 이어서 계기판 17, ABS 03, 에어백 15, 편의 46, 중앙 전장 09를 읽어요. 응답하지 않는 제어 장치는 그냥 장착되지 않은 것일 수 있어요.
5. **보고서 저장**은 Caruspex 설정 폴더 안의 `test-reports` 폴더에 텍스트 파일과 JSON 파일을 만들어요. **GitHub에서 테스트 보고서 열기**는 보고서 양식을 대신 채워 줘요. 체크하지 않으면 VIN과 이모빌라이저 번호는 줄여서 들어가요.

결과의 의미:

| 결과 | 할 일 |
|---|---|
| 에코 없음 | 케이블이 자기 신호를 듣지 못해요: 플러그가 제대로 꽂히지 않았거나 16번 핀에 12 V가 없어요(진단 단자의 퓨즈를 점검하세요). 차 없이는 이게 정상이에요. |
| 에코가 깨졌습니다 | 단자에 다른 장치가 있거나, K+DCAN 케이블의 스위치가 K-Line에 있지 않거나, 케이블이 불량이에요. |
| 깨우기 주소의 타이밍이 너무 고르지 않습니다 | 비트가 200 ms에서 20 ms 넘게 벗어나요: USB 허브 쓰지 않기, 다른 프로그램 닫기, 지연 타이머 1 ms. Caruspex는 Break 호출을 앞당겨 한 번 더 시도해요. |
| 케이블은 정상이지만 차에서 응답이 없습니다 | 시동 스위치를 켰나요? 주소 01이 엔진이에요. 2005년경 이후의 차는 CAN으로 진단해요. |
| 키 바이트 응답이 너무 늦었습니다 | 지연 타이머를 1 ms로 설정하세요. |

## 흔한 문제

- **제어 장치가 응답하지 않음**: 점화 스위치는 켰나요? 5 baud 웨이크업은 정확한 타이밍이 필요해요. USB 허브와 일부 가상 머신은 이를 망가뜨리니, 케이블을 직접 연결하세요.
- **잠시 후 끊김**: 저렴한 케이블은 바이트를 잃어버려요. 차를 의심하기 전에 다른 케이블을 써 보세요.
