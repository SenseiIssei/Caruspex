# USB로 연결하는 ELM327

OBD 단자에 꽂는 플러그에 USB 포트로 가는 케이블이 달린 형태예요. 가장 믿을 만한 ELM327이에요: 페어링도, 무선 신호도, 방전된 배터리도 없어요.

## 드라이버

플러그 안의 USB 칩이 케이블을 시리얼 포트(Windows에서는 COM 포트)로 바꿔 줘요. 어떤 드라이버가 필요한지는 이 칩에 따라 달라요:

| 칩 | 드라이버 |
|---|---|
| FTDI FT232 | 보통 Windows가 직접 설치, Linux와 macOS에는 기본 포함 |
| CH340 / CH341 | 보통 Windows가 직접 설치, Linux와 macOS에는 기본 포함 |
| Silicon Labs CP210x | Windows가 찾지 못하면 제조사 웹사이트에서 |
| Prolific PL2303 | 제조사 웹사이트에서, 오래된 복제품은 예전 드라이버로만 작동하는 경우가 많음 |

꽂고 나면 Windows 장치 관리자의 "포트(COM & LPT)" 아래에 어댑터가 나타나요.

## 연결하기

1. 어댑터를 차에 꽂고 점화 스위치를 켠 다음 케이블을 컴퓨터에 꽂아요.
2. **연결** 페이지에서 **USB 또는 COM 포트**를 골라요.
3. 포트는 **자동 검색**으로 두거나 목록에서 고른 다음 연결해요.

자동 검색은 모든 시리얼 포트를 흔히 쓰는 속도로 시도해요. 내 어댑터의 속도를 알고 있다면 설정의 **어댑터 통신 속도(baud)**에서 지정할 수 있어요.

## Linux와 macOS

Linux에서는 어댑터가 `/dev/ttyUSB0` 또는 `/dev/ttyACM0`으로 나타나요. 사용자가 `dialout` 그룹에 들어 있어야 해요([설치](install.md) 참고). macOS에서는 `/dev/cu.usbserial-...` 또는 `/dev/cu.wchusbserial...`로 나타나요.

## 흔한 문제

- **포트가 나타나지 않음**: 드라이버가 없거나, 케이블이 충전 전용이에요.
- **어댑터는 응답하는데 차가 응답하지 않음**: 점화 스위치가 꺼져 있거나, 어댑터가 그 차의 프로토콜을 처리하지 못하는 복제품이에요. [어댑터 시험](interfaces.md)으로 더 자세히 알 수 있어요.
- **오래된 차에서 실시간 값이 아주 느림**: K-Line 자체가 느린 것이지 어댑터 탓이 아니에요.
