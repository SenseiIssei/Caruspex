# Caruspex

Caruspex는 자동차와 오토바이를 위한 무료 진단 프로그램이에요. Windows, Linux, macOS에서 실행되고, 18개 언어를 지원하며, 사람들이 실제로 가지고 있는 어댑터로 작동해요: 저렴한 ELM327 플러그, OBDLink, 오래된 Volkswagen 그룹 차용 KKL 케이블, BMW용 ENET 케이블, 그리고 전문가용 CAN 인터페이스.

![실시간 게이지가 있는 개요 화면](screenshot-overview.png)

## 할 수 있는 일

- 고장 코드를 읽고 지우고, 쉬운 말로 설명하고, 계속 운전해도 되는지 알려 줘요.
- 실시간 값을 보여 줘요: 온도, 속도, 혼합비, 과급압, 배터리 전압 등 많은 값을 숫자와 그래프로.
- 차와 어댑터가 허용하는 한, 엔진만이 아니라 차의 모든 제어 장치에 물어봐요.
- 중고차를 사기 전에 점검해요: VIN이 맞는지, 주행 거리가 일치하는지, 직전에 고장이 지워지지 않았는지.
- 차를 유리 모형으로 보여 주고, 고장과 값이 제자리에서 빛나요.
- 다음에 무엇을 해야 할지 알려 줘요: 지금 바로 정차, 곧 정비소로, 또는 기다려도 됨.

## 어디서 시작할까요

1. 컴퓨터에 [Caruspex를 설치](install.md)하세요.
2. [첫걸음](first-steps.md)을 따라 하세요: 먼저 데모 차량을 써 보고, 그다음 내 차를 연결해요.
3. [어댑터와 인터페이스](interfaces.md)에서 내 어댑터를 찾아보세요.
4. Caruspex가 무엇을 저장하고 보내는지 [개인정보](privacy.md)에서 읽어 보세요. 요약하면: 직접 공유하지 않는 한 아무것도 컴퓨터 밖으로 나가지 않아요.

> Caruspex는 읽기만 해요. 제어 장치를 코딩하지 않고, 주행 거리를 바꾸지 않고, 이모빌라이저에는 손대지 않아요. 고장 코드 삭제가 차에 쓰는 유일한 작업이에요.

## 솔직한 현황

Caruspex는 사양서를 따라 만들었고, 시뮬레이션한 제어 장치, 가짜 게이트웨이, 가짜 드라이버로 테스트하고 있어요. 실제 하드웨어로는 지금까지 STN2232 칩이 들어간 OBDLink 하나만 확인했고, 그것도 차 없이 확인했어요. 내 차에서 Caruspex를 써 봤다면 [테스트 보고서](https://github.com/SenseiIssei/Caruspex/issues/new?template=test-report.yml)를 보내 주세요: 보고서 하나하나가 테스트된 차 목록을 늘려 줘요.
