# SAE J2534 PassThru

J2534는 Windows에서 전문 진단 장비를 쓰기 위한 표준 인터페이스예요: Tactrix OpenPort 2.0, Drew Technologies Mongoose, VCX Nano, Scanmatik, Godiag, J2534 모드의 VAS 5054A 등. 장비마다 제조사의 드라이버 DLL이 함께 오고, Caruspex는 그 드라이버를 사용해요.

## 연결하기

1. 제조사의 드라이버를 설치해요. 드라이버가 Windows에 스스로 등록되고, Caruspex가 거기서 찾아요.
2. **연결** 페이지에서 **CAN 인터페이스**를 고르고, 목록에서 장비와 비트레이트(CAN을 통한 OBD는 500 kbit/s)를 골라요.
3. 연결해요. 장비가 측정할 수 있으면 배터리 전압이 표시돼요.

## 되는 것

- **CAN**: Caruspex가 날것의 CAN 프레임을 받아서 ISO-TP를 직접 처리하므로, OBD, UDS를 통한 모든 제어 장치, 빠른 병렬 제어 장치 검색이 작동해요.
- **VW TP 2.0**: 2004년부터 2012년경까지의 VW, Audi, Seat, Skoda의 모든 제어 장치. ELM327로는 닿지 않아요.
- **K-Line** (ISO 9141과 14230): 오래된 차를 위해 KKL 페이지에도 J2534 장비가 표시돼요.
- **CAN FD** (지원하는 장비만): 연결 페이지에서 CAN FD 상자를 체크해요.

## 오래된 32비트 드라이버

오래된 장비 상당수는 32비트 드라이버만 있어요. 그러면 Caruspex가 `caruspex.exe` 옆에 있는 작은 도우미 프로그램 `caruspex-j2534-bridge.exe`를 실행해서, 거기서 드라이버를 불러오고 모든 호출을 로컬 파이프로 전달해요. 장비 목록에는 이런 드라이버도 사용 가능으로 표시돼요.

## 한계

- J2534 자체와 마찬가지로 Windows 전용이에요.
- 아직 실제 J2534 장비로 테스트하지 않았어요: 테스트는 실제 드라이버처럼 동작하는 가짜 드라이버로 하고 있어요.

## 명령줄

```
caruspex_cli interfaces
caruspex_cli read --can "j2534:<name of the device>@500000"
```

`caruspex_cli interfaces`가 정확한 이름을 출력해요.
