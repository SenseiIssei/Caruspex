# 실시간 값

**실시간 값** 페이지(전문가 모드)는 센서가 지금 측정하는 값을 보여 줘요. 초보자 모드에서는 **주행 모드**가 가장 중요한 값을 큰 글씨로 보여 줘요.

![실시간 값](screenshot-live.png)

## 볼 수 있는 것

- SAE J1979 모드 01의 PID C4까지 모든 값: 145개 PID, 300개가 넘는 측정값을 그룹으로 나누고 검색할 수 있어요. 내 차가 어떤 값을 지원하는지는 차가 직접 알려 줘요.
- 주행 거리계, 기어, 엔진오일 온도, 연료 소비율, 토크, 과급압, 배기 온도, 매연 필터(DPF), AdBlue, NOx, 하이브리드 배터리. 차가 보고하는 범위에서요.
- 여러 값을 한꺼번에 보여 주는 흐르는 그래프. 긴 시간 범위(최대 1시간)에서는 오래된 점을 솎아 내지만 모든 최고점과 최저점은 남겨요.
- CSV로 기록.

## 제조사 값과 직접 추가하는 값

- **전기차 배터리**: 배터리 수명 상태, 충전량, 편차를 포함한 셀 전압, 온도. Hyundai Kona와 Ioniq, Kia e-Niro, Renault Zoe, Nissan Leaf, Tesla Model 3와 Y(CAN 버스 수신으로)를 지원하며, **EV 배터리** 페이지에 있어요.
- **OBDb 값**: 약 550개 차종의 추가 값(타이어 공기압, 오일, 주행 거리계 등). 감지한 차에 맞춰 저절로 제공돼요.
- **직접 추가하는 값**: 널리 쓰이는 Torque CSV 형식으로, 계산식도 포함해서.

![EV 배터리](screenshot-battery.png)

## 얼마나 빠른가요?

초당 얼마나 많은 값이 들어오는지는 차와 어댑터에 따라 달라요. CAN 차는 빠르게 응답하고, K-Line 차는 원래 느리게 설계되어 있어요. OBDLink를 쓰면 Caruspex가 한 번에 최대 24개 값을 요청할 수 있어요([OBDLink와 STN](obdlink-stn.md) 참고). 원시 CAN 인터페이스가 가장 빠른 방법이에요.

## 기록과 재생

차와 주고받은 세션 전체를 파일로 기록해 두었다가 나중에 차 없이 재생할 수 있어서, 고장 원인을 찾을 때 편리해요. **기록 공유**로 개인 데이터를 뺀 기록을 프로젝트용으로 준비할 수 있어요. [개인정보](privacy.md)를 참고하세요.
