# 고장

**고장 메모리** 페이지는 제어 장치에 저장된 내용을 읽고 쉬운 말로 설명해 줘요.

![고장 메모리](screenshot-faults.png)

## 보이는 것

- **저장됨, 대기 중, 영구** 코드. 제어 장치가 여러 개면 코드마다 어디서 보고했는지(엔진, 변속기) 표시돼요.
- 약 1,400개의 표준 코드(P, C, B, U)와 VAG, Ford, GM, Toyota, Honda, Nissan, Hyundai와 Kia, Subaru 등의 제조사 코드. P1 코드는 감지한 브랜드의 의미대로 읽어요.
- 코드마다 **신호등** 표시와, 누구나 가장 먼저 묻는 질문에 대한 답: 계속 운전해도 되나요?
- 흔한 원인, 직접 점검할 수 있는 것, 대략적인 비용 등급.
- 부품이 어디에 있는지: 투명하게 보이는 차, 또는 [투시 보기](xray.md).

## 모든 제어 장치

전문가 모드에서 **모든 제어 장치** 페이지는 엔진만이 아니라 모든 제어 장치에 물어봐요: ABS, 에어백, 계기판, 에어컨 등. 고장마다 고장 유형(단락, 단선, 신호 이상), 부품 번호, 소프트웨어 버전이 함께 나와요. 오래된 VW 그룹 차는 [KKL 케이블](kkl.md)로 읽어요.

## 지금 무엇을 해야 할까요?

**무엇을 할까?** 페이지는 Caruspex가 찾은 모든 것을 세 단계로 나눠요: 지금 바로 정차, 곧 정비소로, 기다려도 됨. 항목마다 이유를 설명하는 쉬운 문장 하나, 대략적인 비용 범위, 정비소에서 보여 줄 메모가 붙어요. 엔진 경고등이 깜빡이는지, 빨간 경고등이 켜졌는지는 OBD로 알 수 없어서 두 개의 체크 상자로 물어봐요. 경고등이 깜빡이고 실화가 있으면 그 항목은 "지금 바로 정차"로 옮겨져요.

![지금 무엇을 해야 할까요](screenshot-todo.png)

## 코드 삭제

삭제는 제어 장치별로 할 수 있고, 분명한 경고가 나온 뒤에 진행돼요. 삭제한 직후 Caruspex가 메모리를 다시 읽어요.

> 삭제는 수리가 아니에요. 준비 상태 모니터도 초기화돼요: 차가 완전한 주행 사이클을 여러 번 마칠 때까지 배출가스 검사를 통과하지 못하고, 원인이 그대로인 코드는 조금만 달려도 다시 나타나요.
