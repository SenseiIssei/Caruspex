# 개인정보

Caruspex는 내 컴퓨터에서 작동해요. 계정도, 클라우드도, 추적도 없어요.

## 저장되는 것

모든 것이 내 컴퓨터에 남아요:

| 무엇을 | 언제 | 어디에 |
|---|---|---|
| 설정 | 항상 | 시스템의 설정 폴더(설정의 **저장 위치 열기** 버튼으로 볼 수 있어요) |
| 차고: VIN, 차, 점검, 주행 거리 기록, 마지막으로 성공한 연결 방법 | 차를 연결한 뒤 | 설정 옆, Caruspex 데이터 폴더 안 |
| 기록과 CSV 파일 | 직접 시작했을 때만 | 저장한 곳 |
| 로그 파일 | 설정에서 켰을 때만 | 선택한 경로 |
| 충돌 보고서 | Caruspex가 충돌했을 때만 | 차고 옆의 `crash-reports` 폴더 |
| KKL 첫 테스트 보고서 | 보고서를 저장할 때만 | 설정 폴더 안의 `test-reports` 폴더. 확인란을 선택하지 않으면 VIN과 이모빌라이저 번호가 줄여서 저장됩니다 |

이 파일들은 언제든지 지울 수 있어요.

## 보내지는 것

설치할 때마다, 이전 버전에서 업데이트한 뒤에도, Caruspex는 한 번 업데이트를 확인해도 되는지 묻습니다. "예"라고 답한 뒤에야 시작할 때와 실행 중 여섯 시간마다 GitHub에 새 버전이 있는지 묻습니다. 이때 나나 내 차에 대한 정보는 아무것도 보내지 않아요. "예"라고 답하지 않으면 GitHub로 어떤 요청도 가지 않아요. 이 설정은 **창과 언어**에서 언제든 바꿀 수 있어요. 그 밖에 Caruspex는 인터넷에 연결하지 않아요. Wi-Fi 어댑터, ENET 케이블, DoIP 차와의 통신은 로컬 네트워크 안에서만 이루어져요.

업데이트를 확인하는 것은 GitHub에 공개된 릴리스 빌드뿐이며, 직접 빌드한 사본은 절대 확인하지 않습니다. Caruspex가 업데이트를 확인하거나 내려받을 때, 다른 모든 다운로드와 마찬가지로 GitHub는 컴퓨터의 IP 주소와 Caruspex 버전을 보게 됩니다. Caruspex 자체는 그 밖의 것을 보내거나 저장하지 않으며, 프로젝트를 포함해 다른 누구도 이를 볼 수 없습니다. 여기에는 GitHub의 개인정보 처리방침이 적용됩니다. 업데이트는 Caruspex 저장소의 릴리스에서만 내려받습니다. **GitHub에 보고** 같은 버튼은 브라우저를 열 뿐이며, 거기서 무엇을 올릴지는 사용자가 정합니다.

## Android

Android 11까지는 위치 권한이 있어야 앱이 Bluetooth LE 어댑터를 찾을 수 있습니다. Caruspex는 이 이유로만 권한을 요청하며 위치를 읽지 않습니다. Android 12부터는 대신 위치에 사용하지 않는다고 표시된 블루투스 권한을 요청합니다.

## 충돌 보고서는 원할 때만

Caruspex가 충돌하면 내 컴퓨터에 짧은 보고서를 써요: 버전, 시스템, 코드 위치, 호출 경로. VIN, 차와 주고받은 바이트, 홈 폴더는 잘라 내요. 아무것도 보내지 않아요. Caruspex는 보고서를 보여 주고 두 개의 버튼을 제공해요: **GitHub에 보고**는 브라우저에서 미리 채워진 이슈를 여는데, 올리기 전에 읽고 고칠 수 있어요. **보고하지 않음**은 보고서를 치워 둬요.

## 개인 데이터 없이 기록 공유하기

실제 차의 기록은 Caruspex가 더 많은 차를 지원하는 데 도움이 돼요. **기록 공유**는 사본을 준비하고, 무엇이 남고 무엇이 빠지는지 정확히 보여 줘요:

- **빠지는 것**: VIN의 마지막 자리들(파일 안의 모든 곳), 포트 이름, 어댑터의 Bluetooth 주소나 네트워크 주소, 시각.
- **기록에 절대 들어가지 않는 것**: 내 위치와 사용자 데이터.
- **남는 것**: 요청과 응답, 어댑터 종류, 프로토콜, 날짜.

파일은 내가 직접 저장해서 GitHub 이슈에 첨부할 때까지 내 컴퓨터에 남아요. 자동으로 올라가는 것은 아무것도 없어요.
