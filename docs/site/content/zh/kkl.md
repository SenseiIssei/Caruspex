# KKL 线（VAG 409.1）

KKL 线是一根带串口芯片和 K-Line 驱动器的 USB 线，里面没有 ELM327。Caruspex 自己逐字节地驱动 K-Line。老款 VW、Audi、Seat 和 Skoda 需要的正是这个：它们的协议 KWP1281 要对每一个字节逐一确认，这是任何 ELM327 都做不到的。

## 能做什么

- 大约 1990 到 2004 年的 VW、Audi、Seat 和 Skoda 的每一个控制单元：发动机、变速箱、ABS、安全气囊、仪表、舒适系统等等。
- KWP1281 和 KWP2000（ISO 14230），唤醒后根据关键字节自动识别。
- 按控制单元读取故障存储器、测量数据块，以及真正的节气门体基本设定（测量数据块 060 或 098）。
- 匹配通道特意设为只读。输出测试会真的驱动部件，确认后才会开始。

这些页面在**专业模式**里：**通过 KKL 的控制单元**、**节气门体** 和 **适配与输出测试**。每个页面都会自己打开这根线：选择串口、控制单元，然后开始。

## 用哪种线？

带正品 FTDI FT232RL 或 CP2102 的线，在 K-Line 上比最便宜的克隆品可靠得多。KWP1281 建议用正品 FTDI。这根线必须把 K-Line 原样透传：带自己固件的“HEX-USB”接口不能用。

大约 1996 年以前的车往往没有 OBD 诊断座，而是在发动机舱或仪表台下有一个 2x2 插头。2x2 转 16 针诊断座的转接头很便宜。

## 检查这根线

命令行工具不接车也能测试这根线：

```
caruspex_cli kklcheck --port COM3
```

## 常见问题

- **控制单元没有应答**：点火开关打开了吗？5 波特唤醒需要精确的时序；USB 集线器和某些虚拟机会把它搞乱，请把线直接插在电脑上。
- **过一会儿就断开**：便宜的线会丢字节。在怀疑车有问题之前，先换一根线试试。
