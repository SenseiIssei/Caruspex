# KKL 线（VAG 409.1）

KKL 线是一根带串口芯片和 K-Line 驱动器的 USB 线，里面没有 ELM327。Caruspex 自己逐字节地驱动 K-Line。老款 VW、Audi、Seat 和 Skoda 需要的正是这个：它们的协议 KWP1281 要对每一个字节逐一确认，这是任何 ELM327 都做不到的。

## 能做什么

- 大约 1990 到 2004 年的 VW、Audi、Seat 和 Skoda 的每一个控制单元：发动机、变速箱、ABS、安全气囊、仪表、舒适系统等等。
- KWP1281 和 KWP2000（ISO 14230），唤醒后根据关键字节自动识别。
- 按控制单元读取故障存储器、测量数据块，以及真正的节气门体基本设定（测量数据块 060 或 098）。
- 匹配通道特意设为只读。输出测试会真的驱动部件，确认后才会开始。

这些页面在**专业模式**里：**通过 KKL 的控制单元**、**节气门体** 和 **适配与输出测试**。每个页面都会自己打开这根线：选择串口、控制单元，然后开始。

## 用哪种线？

带正品 FTDI FT232RL 或 CP2102 的线，在 K-Line 上比最便宜的克隆品可靠得多。KWP1281 建议用正品 FTDI。这根线必须把 K-Line 原样透传：带自己固件的“HEX-USB”接口不能用。

大约 1996 年以前的车往往没有 OBD 诊断座，而是在发动机舱或仪表台下有一个 2x2 插头。2x2 转 16 针诊断座的转接头很便宜。

## 检查这根线

命令行工具不接车也能测试这根线：

```
caruspex_cli kklcheck --port COM3
```

## 首次实车测试

专业模式页面 **首次实车测试** 会带你完成新 KKL 线的第一次使用。它专为 Audi A2 定制，也适用于任何带 K-Line 的 VW、Audi、Seat 或 Skoda。只读取：不清除任何内容，不做输出测试，不做基本设定。端口只在测试开始时才打开。

1. **不接车检查线缆。** 线缆只插到 USB 上，选择它的端口，然后点击 **检查线缆**。Caruspex 读取芯片（FTDI、CH340、Prolific、CP210x），若是 FTDI 还会读取延迟计时器，并在 Break 线上测量 5 波特地址的各个位。不接车时没有回显，这是正常的。
2. **把延迟计时器设为 1 ms**（Windows 上的 FTDI 线）：设备管理器，端口 (COM 和 LPT)，双击 USB Serial Port，端口设置，高级，把 Latency Timer (msec) 设为 1，OK，然后把线拔下再插上一次。默认值为 16 ms 时，对关键字节的回复可能错过 50 ms 的时间窗口。Caruspex 会读取这个设置，但从不更改它。
3. **接车：** 点火开关打开，发动机熄火，线缆牢牢插在 OBD 诊断座里并直接接在电脑上（不用 USB 集线器），没有打开其他诊断程序。勾选清单，然后点击 **开始首次测试**。
4. 测试会唤醒发动机（地址 01），并测量地址的每一位、同步字节 0x55、关键字节以及对它们的回复。然后读取标识、故障存储器和测量数据块 001 到 003，之后是仪表盘 17、ABS 03、安全气囊 15、舒适系统 46 和中央电气 09。没有应答的控制单元可能只是没有安装。
5. **保存报告** 会把一个文本文件和一个 JSON 文件写入 Caruspex 设置文件夹中的 `test-reports` 文件夹。**在 GitHub 上打开测试报告** 会替你填好报告表单。除非勾选该选项，否则 VIN 和防盗锁止系统编号会被截短。

结果的含义：

| 结果 | 怎么办 |
|---|---|
| 没有回显 | 线缆听不到自己：插头没插好，或 16 号针脚没有 12 V（检查诊断座的保险丝）。不接车时这是正常的。 |
| 回显失真 | 诊断座上有其他设备，K+DCAN 线的开关没拨到 K-Line，或线缆有故障。 |
| 唤醒地址的时序太不精确 | 位与 200 ms 相差超过 20 ms：不要用 USB 集线器，关闭其他程序，延迟计时器设为 1 ms。Caruspex 会提前发出 Break 调用，再试一次。 |
| 线缆正常，但车辆没有应答 | 点火开关打开了吗？地址 01 是发动机。约 2005 年以后的车通过 CAN 诊断。 |
| 对关键字节的回复太晚 | 把延迟计时器设为 1 ms。 |

## 常见问题

- **控制单元没有应答**：点火开关打开了吗？5 波特唤醒需要精确的时序；USB 集线器和某些虚拟机会把它搞乱，请把线直接插在电脑上。
- **过一会儿就断开**：便宜的线会丢字节。在怀疑车有问题之前，先换一根线试试。
