# BMW ENET 线

BMW 和 Mini 从 F 系列起（大约 2008 年以后）在 OBD 诊断座上有以太网。ENET 线从 OBD 诊断座直接连到电脑的网口，中间没有适配器芯片。Caruspex 通过 HSFZ 和车辆的网关通信（端口 6811 和 6801），可以访问每一个控制单元。

## 连接

1. 把线插到车上和电脑的网口上（或者 USB 网卡上）。打开点火开关。
2. 最多等一分钟：没有 DHCP 服务器时，Windows、macOS 和 Linux 会自己给电脑分配一个自动地址（169.254.x.x）。
3. 在 **连接** 页面选择 **网线**，输入框留空：Caruspex 会在网络中寻找车辆。如果什么都没找到，就输入车辆的地址。

## 能做什么

- 通过 UDS 和 BMW 的寻址方式访问每一个控制单元，故障码按 BMW 的格式显示，和 ISTA 一样（例如 480A10）。
- 按控制单元读取故障存储器、识别信息和清除故障，通过 OBD 读取实时数据。
- 在这里 Caruspex 也只读取。编码和刷写仍然交给维修厂的专业软件。

## 用哪种线？

普通的 ENET 线在第 8 针和第 16 针之间有一个电阻，用来打开车辆的以太网。没有这个电阻的线，车不会有反应。1 Gbit/s 的网口可以用，车辆使用 100 Mbit/s。

## 命令行

```
caruspex_cli ecus --enet auto
```
