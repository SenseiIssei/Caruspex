# 通过 Wi-Fi 连接 ELM327

有些适配器会开一个自己的 Wi-Fi 网络。电脑连上这个网络，通过 TCP 和适配器通信。

## 连接

1. 插上适配器，打开点火开关。几秒钟后会出现一个 Wi-Fi 网络，名字通常是 `WiFi_OBDII`、`V-LINK` 或厂商的名字。
2. 用电脑连接这个网络。它没有互联网，所以系统可能会提示连接受限：这没关系。
3. 在 Caruspex 的 **连接** 页面选择 **WLAN**。大多数适配器使用地址 `192.168.0.10` 和端口 `35000`，这已经预设好了。如果你的适配器用的是别的地址（例如 `192.168.4.1`），请按 `address:port` 的格式输入。

## 小贴士

- 电脑连在适配器的网络里时，就上不了网。这对 Caruspex 没有影响。
- Wi-Fi 适配器在所有系统上都不需要驱动。
- 如果连接中断，把电脑挪得离车近一点：这类插头的无线信号很弱。
