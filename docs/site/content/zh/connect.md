# 连接助手与 OBD 诊断座

## 诊断座在哪里？

2001 年起（汽油车）或 2004 年起（柴油车）在欧洲销售的汽车，以及 1996 年起在美国销售的汽车，都有一个 16 针的 OBD 诊断座，驾驶员伸手就能够到。常见位置：

- 仪表台下方，转向柱左侧或右侧，
- 踏板上方，
- 脚坑的侧饰板里，
- 保险丝盒盖板后面，
- 中控台里，有时藏在一个小翻盖后面。

Caruspex 知道 200 多代车型和 35 款摩托车的诊断座确切位置。连接助手会在俯视图和驾驶员侧的特写图中标出位置；对于摩托车，它会显示一张侧视图，标出诊断插头和所需的转接线。

> 诊断座位置列表是我们自己收集的，并没有在每辆车上核实过。如果你车上的位置不对，请通过[测试报告](https://github.com/SenseiIssei/Caruspex/issues/new?template=test-report.yml)告诉我们。

## 连接助手

首次启动时助手会自动打开。它会问四件事，每一步都可以跳过：

1. **用哪个适配器？** USB、蓝牙或 Wi-Fi 的 ELM327、ENET 线或 KKL 线。图片可以帮你区分它们。
2. **哪辆车？** 从车型目录中选出你的车，助手就会显示诊断座的位置。
3. **打开点火开关。** 大多数控制单元只有在点火开关打开时才会应答。
4. **连接。** Caruspex 会搜索端口并尝试各种协议。

之后你可以在设置和“连接”页面中再次找到助手。

## 搜索与记忆

使用自动搜索时，Caruspex 会逐个检查所有串口，问每个端口上是否有 ELM327，然后逐一尝试这辆车的协议。一旦某辆车连接成功，Caruspex 就会按它的 VIN 记住这条连接方式（适配器、端口、协议、比特率），下次优先尝试，连接也就更快。

## 连不上时

如果没有适配器应答，或者车辆一直没有反应，Caruspex 会针对这种连接方式显示一份简短的检查清单，并附上它已经查明的情况：驱动是否已安装、蓝牙是否已配对、点火开关是否打开、比特率是否正确、是不是只冒充新版本的克隆适配器。[适配器与接口](interfaces.md)下的各页会详细说明每一种连接方式。
