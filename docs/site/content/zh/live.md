# 实时数据

**实时数据** 页面（专业模式）显示传感器此刻测到的数值。在新手模式下，**驾驶模式** 会用大字显示最重要的数据。

![实时数据](screenshot-live.png)

## 有哪些数据

- SAE J1979 模式 01 中直到 PID C4 的所有数据：145 个 PID，300 多项读数，分组显示并可搜索。你的车支持哪些，它自己会告诉你。
- 里程表、挡位、机油温度、油耗、扭矩、增压、排气温度、颗粒捕集器、AdBlue、NOx 和混动电池，只要车辆会报告。
- 可同时显示多项数据的滚动曲线图。在长时间窗口（最长一小时）下，曲线会把旧的点稀疏化，但保留每一个峰值和谷值。
- 记录到 CSV。

## 厂家数据和自定义数据

- **电动车电池**：健康状态、电量、单体电压（含压差）和温度，支持 Hyundai Kona 和 Ioniq、Kia e-Niro、Renault Zoe、Nissan Leaf 以及 Tesla Model 3 和 Y（通过监听 CAN 总线），在 **电动车电池** 页面。
- **OBDb 数据**：另外约 550 款车型的数据（胎压、机油、里程表等），会针对识别出的车辆自动提供。
- **自定义数据**：使用广泛的 Torque CSV 格式，包括公式。

![电动车电池](screenshot-battery.png)

## 有多快？

每秒能收到多少数据取决于车辆和适配器。CAN 总线的车应答很快；走 K-Line 的车本来就慢。用 OBDLink 时，Caruspex 一次最多可以请求 24 项数据（见 [OBDLink 与 STN](obdlink-stn.md)）；原始 CAN 接口是最快的方式。

## 记录与回放

和车的整个会话都可以记录到一个文件里，之后不接车也能回放，排查故障时很方便。用 **分享记录** 可以把一段记录去掉个人数据后准备好提供给项目，见[隐私](privacy.md)。
