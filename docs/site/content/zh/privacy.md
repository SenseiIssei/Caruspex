# 隐私

Caruspex 在你的电脑上运行。它没有账号，没有云，也不做任何跟踪。

## 存储了什么

所有东西都留在你的电脑上：

| 内容 | 何时 | 位置 |
|---|---|---|
| 设置 | 始终 | 系统的设置文件夹（设置中的 **打开存储位置** 按钮会显示它） |
| 车库：VIN、车辆、检查记录、里程读数、上一次可用的连接方式 | 连接车辆后 | 在设置旁边，Caruspex 的数据文件夹里 |
| 记录和 CSV 文件 | 只在你开始记录时 | 你保存的位置 |
| 日志文件 | 只在你在设置中打开它时 | 你选择的路径 |
| 崩溃报告 | 只在 Caruspex 崩溃时 | 车库旁边的 `crash-reports` 文件夹 |
| KKL 首次测试的报告 | 仅在你保存报告时 | 设置文件夹中的 `test-reports` 文件夹；除非你勾选该选项，否则 VIN 和防盗系统编号会被截短 |

这些文件你随时都可以删除。

## 发送了什么

启动时，Caruspex 会向 GitHub 询问是否有新版本。这时不会发送任何关于你或你车辆的信息。这个检查可以在设置中关闭。除此之外，Caruspex 不会连接互联网。和 Wi-Fi 适配器、ENET 线或 DoIP 车辆的通信都只在你的本地网络中进行。

只有发布在 GitHub 上的正式版本才会检查更新；你自己编译的副本从不检查。与互联网上的任何请求一样，检查和下载更新时 GitHub 会看到你的 IP 地址和 Caruspex 的版本，这适用 GitHub 的隐私声明。更新只从 Caruspex 仓库的发布页下载。**在 GitHub 上报告** 之类的按钮只会打开你的浏览器；在那里发布什么由你决定。

## Android

在 Android 11 及更早版本上，系统只允许应用在获得位置权限后查找 Bluetooth LE 适配器。Caruspex 仅因此申请该权限，从不读取你的位置。从 Android 12 起，它改为申请蓝牙权限，并声明从不用于定位。

## 崩溃报告只在你要求时发送

如果 Caruspex 崩溃，它会在你的电脑上写一份简短的报告：版本、系统、出错的代码位置和调用链。VIN、车辆通信的字节和你的主文件夹都会被去掉。什么都不会发送。Caruspex 会把报告给你看，并提供两个按钮：**在 GitHub 上报告** 会在浏览器中打开一个预先填好的 issue，你可以在发布前阅读和修改；**不报告** 则把它放到一边。

## 去掉个人数据后分享记录

真实车辆的记录有助于让 Caruspex 支持更多的车。**分享记录** 会准备一份副本，并清楚地告诉你哪些保留、哪些去掉：

- **去掉**：VIN 的最后几位（文件中所有出现的地方）、端口名称、适配器的蓝牙或网络地址、具体时间。
- **记录中从不包含**：你的位置和用户数据。
- **保留**：请求和应答、适配器类型、协议和日期。

这个文件会一直留在你的电脑上，直到你自己保存它并附加到 GitHub issue 中。不会有任何东西被自动上传。

## 测试计划

[测试报告表单](https://github.com/SenseiIssei/Caruspex/issues/new?template=test-report.yml)会询问车辆、年份、发动机和适配器。它只要缩短后的 VIN；请不要发布完整的 VIN、你的车牌号或你的名字。
