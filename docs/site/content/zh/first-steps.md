# 第一步

## 1. 试试演示车

不需要真车也能四处看看。在 **连接** 页面选择 **演示车辆**：它会行驶、会升温、存着几个故障，应答方式和真正的 ELM327 一样。所有页面都能用它。

## 2. 选择语言和模式

Caruspex 跟随系统语言。在 **设置** 中可以从 18 种语言中选一种，也可以选浅色或深色外观；两者都在下次启动时生效。

**新手模式** 显示日常使用的页面。**专业模式** 会加上维修厂用的工具：KKL 页面、匹配、适配器原始命令和控制单元地址。

## 3. 连接你的车

1. 找到诊断座：[连接助手](connect.md)会告诉你它在你车上的位置。
2. 插上适配器，打开点火开关。发动机可以着车，但不是必须的。
3. 在 **连接** 页面选择连接方式，或者让 Caruspex 自己搜索所有端口。

首次启动时，连接助手会自动打开。每一步都可以跳过，之后也可以从设置和“连接”页面再次打开助手。

![连接页面](screenshot-connect.png)

## 4. 先看看这辆车

连接后，Caruspex 会读取 VIN，并告诉你这是哪辆车。适合开始的地方：

- **健康检查**：一个按钮，半分钟，给出 0 到 100 的分数，每扣一分都有解释。
- **我现在该怎么办？**：所有发现的问题，分成三档。
- [故障存储器](faults.md)和[实时数据](live.md)。

![健康检查](screenshot-health.png)

## 5. 车库和报告

每辆车都通过 VIN 识别，并在车库里有自己的条目，记录检查历史和里程读数。检测报告可以保存为 PDF 交给修理厂。
