# DoIP（基于 IP 的诊断）

大约 2016 年以后的许多汽车可以按照 ISO 13400 通过以太网进行诊断，这就是 DoIP。DoIP 线把 OBD 诊断座和电脑的网口连起来。

## 连接

1. 插上线，打开点火开关，等电脑获得自动地址（169.254.x.x），这可能需要一分钟左右。
2. 在 **连接** 页面选择 **网线**，输入框留空。Caruspex 会在网络中寻找 DoIP 车辆，并自动识别这辆车用的是 DoIP 还是 BMW 的 HSFZ。

## 能做什么

通过 DoIP 读取 OBD，以及通过 UDS 访问 Caruspex 已知该品牌地址的控制单元。DoIP 车辆的地址列表目前还很短；真实车辆的记录会把它们补充完整（分享的记录里包含什么，见[隐私](privacy.md)）。

## 用哪种线？

DoIP 需要 OBD 诊断座第 3、11、12、13 针上的以太网线路，以及第 8 针上的激活线。针对某个品牌出售的线通常正好是这样接的；BMW 的 ENET 线就是其中之一。

## 命令行

```
caruspex_cli enet
```

会列出网络中找到的 BMW 和 DoIP 车辆。
