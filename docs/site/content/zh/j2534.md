# SAE J2534 PassThru

J2534 是 Windows 上专业诊断设备的标准接口：Tactrix OpenPort 2.0、Drew Technologies Mongoose、VCX Nano、Scanmatik、Godiag、J2534 模式下的 VAS 5054A 等等。每种设备都带有厂商提供的驱动 DLL，Caruspex 使用的就是这个驱动。

## 连接

1. 安装厂商的驱动。它会在 Windows 中注册自己，Caruspex 会在那里找到它。
2. 在 **连接** 页面选择 **CAN 接口**，从列表中选出设备，并选择比特率（CAN 上的 OBD 用 500 kbit/s）。
3. 连接。如果设备能测量蓄电池电压，就会显示出来。

## 能做什么

- **CAN**：Caruspex 拿到裸的 CAN 帧，自己处理 ISO-TP，所以 OBD、通过 UDS 访问每一个控制单元以及快速并行搜索控制单元都能用。
- **VW TP 2.0**：大约 2004 到 2012 年的 VW、Audi、Seat 和 Skoda 的所有控制单元，这些是 ELM327 访问不到的。
- **K-Line**（ISO 9141 和 14230）：KKL 页面也会列出 J2534 设备，用于老车。
- **CAN FD**，需要设备支持：在“连接”页面勾选 CAN FD。

## 老的 32 位驱动

很多老设备只有 32 位驱动。这时 Caruspex 会启动它的小助手程序 `caruspex-j2534-bridge.exe`（就放在 `caruspex.exe` 旁边），在那里加载驱动，并通过本地管道转发每一个调用。设备列表会把这样的驱动显示为可用。

## 限制

- 只支持 Windows，J2534 本身也是如此。
- 还没有用真正的 J2534 设备测试过：测试是用一个行为和真驱动一样的虚拟驱动进行的。

## 命令行

```
caruspex_cli interfaces
caruspex_cli read --can "j2534:<name of the device>@500000"
```

`caruspex_cli interfaces` 会打印出确切的名称。
