# 通过 USB 连接 ELM327

插在 OBD 诊断座上、用一根线连到 USB 口的插头。这是最可靠的 ELM327：不用配对，没有无线信号问题，也不会没电。

## 驱动

插头里有一块 USB 芯片，把这根线变成一个串口（在 Windows 上是 COM 端口）。需要哪个驱动取决于这块芯片：

| 芯片 | 驱动 |
|---|---|
| FTDI FT232 | Windows 通常会自动安装，Linux 和 macOS 已内置 |
| CH340 / CH341 | Windows 通常会自动安装，Linux 和 macOS 已内置 |
| Silicon Labs CP210x | 如果 Windows 找不到，从厂商网站下载 |
| Prolific PL2303 | 从厂商网站下载；老的克隆品往往只能用旧驱动 |

插上之后，Windows 的设备管理器会在“端口 (COM 和 LPT)”下显示这个适配器。

## 连接

1. 把适配器插到车上，打开点火开关，再把线插到电脑上。
2. 在 **连接** 页面选择 **USB 或 COM 端口**。
3. 端口保持 **自动搜索**，或者从列表中选择，然后连接。

自动搜索会用常见的速率尝试每一个串口。如果你知道自己适配器的速率，可以在设置里的 **适配器波特率** 中设定。

## Linux 和 macOS

在 Linux 上，适配器显示为 `/dev/ttyUSB0` 或 `/dev/ttyACM0`。你的用户需要在 `dialout` 组里（见[安装](install.md)）。在 macOS 上，它显示为 `/dev/cu.usbserial-...` 或 `/dev/cu.wchusbserial...`。

## 常见问题

- **没有出现端口**：缺少驱动，或者这根线只能充电。
- **适配器有应答，车没有**：点火开关没打开，或者适配器是不支持这辆车协议的克隆品。[适配器测试](interfaces.md)会告诉你更多。
- **老车的实时数据非常慢**：K-Line 本身就慢，这不是适配器的问题。
