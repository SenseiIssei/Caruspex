# Caruspex

Caruspex 是一款免费的汽车和摩托车诊断软件。它可以在 Windows、Linux 和 macOS 上运行，支持 18 种语言，并且能用大家手里真正有的适配器：便宜的 ELM327 插头、OBDLink、用于 Volkswagen 集团老车的 KKL 线、用于 BMW 的 ENET 线，以及专业的 CAN 接口。

![带实时仪表的总览](screenshot-overview.png)

## 它能做什么

- 读取和清除故障码，用通俗的话解释，并告诉你还能不能继续开。
- 显示实时数据：温度、车速、混合气、增压、蓄电池电压等等，既有数字也有曲线图。
- 在车辆和适配器允许的范围内，询问车上的每一个控制单元，而不只是发动机。
- 买二手车前帮你检查：VIN 对得上吗？各处里程一致吗？故障是不是刚被清除过？
- 把车显示成一个玻璃模型，故障和数据会在对应的位置亮起来。
- 告诉你下一步该做什么：马上停车、尽快去修理厂，还是可以等等。

## 从哪里开始

1. 在电脑上[安装 Caruspex](install.md)。
2. 按照[第一步](first-steps.md)操作：先试试演示车，再连接你自己的车。
3. 在[适配器与接口](interfaces.md)中查找你的适配器。
4. 在[隐私](privacy.md)中了解 Caruspex 存储和发送什么。简单说：除非你自己分享，否则什么都不会离开你的电脑。

> Caruspex 只读取。它从不给控制单元编码，从不修改里程，也从不碰防盗器。清除故障码是它唯一会写入车辆的操作。

## 真实现状

Caruspex 是按照规范开发的，并用模拟的控制单元、虚拟网关和虚拟驱动进行测试。在真实硬件上，到目前为止只检查过一个带 STN2232 芯片的 OBDLink，而且没有接车。如果你在自己的车上试用了 Caruspex，请发一份[测试报告](https://github.com/SenseiIssei/Caruspex/issues/new?template=test-report.yml)：每一份报告都会让已测试车辆的列表变得更长。
