# SAE J2534 PassThru

J2534 is the standard interface of professional diagnostic devices on Windows: Tactrix OpenPort 2.0, Drew Technologies Mongoose, VCX Nano, Scanmatik, Godiag, VAS 5054A in J2534 mode and many more. Each comes with a driver DLL from its maker, and Caruspex uses that driver.

## Connecting

1. Install the maker's driver. It registers itself in Windows, and Caruspex finds it there.
2. On the **Connect** page choose **CAN interface**, pick the device from the list and the bit rate (500 kbit/s for OBD over CAN).
3. Connect. The device's battery voltage is shown when it can measure it.

## What works

- **CAN**: Caruspex gets the bare CAN frames and does ISO-TP itself, so OBD, every control unit over UDS and the fast parallel control unit search work.
- **VW TP 2.0**: all control units of VW, Audi, Seat and Skoda from about 2004 to 2012, which an ELM327 cannot reach.
- **K-Line** (ISO 9141 and 14230): the KKL pages also list J2534 devices, for older cars.
- **CAN FD** with devices that support it: switch on the CAN FD box on the Connect page.

## Old 32-bit drivers

Many older devices only have a 32-bit driver. Caruspex then starts its small helper program `caruspex-j2534-bridge.exe`, which lies next to `caruspex.exe`, loads the driver there and passes every call over a local pipe. The device list shows such drivers as usable.

## Limits

- Windows only, like J2534 itself.
- Not yet tested with a real J2534 device: the tests run against a fake driver that behaves like a real one.

## Command line

```
caruspex_cli interfaces
caruspex_cli read --can "j2534:<name of the device>@500000"
```

`caruspex_cli interfaces` prints the exact names.
