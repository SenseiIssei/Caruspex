# ELM327 عبر USB

قابس لمقبس OBD مع كابل إلى منفذ USB. إنه أكثر أنواع ELM327 موثوقية: لا اقتران، ولا اتصال لاسلكي، ولا بطاريات فارغة.

## التعريف

داخل القابس شريحة USB تحوّل الكابل إلى منفذ تسلسلي (منفذ COM على Windows). التعريف المطلوب يعتمد على هذه الشريحة:

| الشريحة | التعريف |
|---|---|
| FTDI FT232 | عادةً يثبّته Windows بنفسه، ومدمج في Linux وmacOS |
| CH340 / CH341 | عادةً يثبّته Windows بنفسه، ومدمج في Linux وmacOS |
| Silicon Labs CP210x | من موقع الشركة المصنّعة إذا لم يجده Windows |
| Prolific PL2303 | من موقع الشركة المصنّعة؛ النسخ المقلّدة القديمة لا تعمل غالبًا إلا مع تعريف قديم |

بعد التوصيل يعرض مدير الأجهزة في Windows المحوّل تحت "المنافذ (COM وLPT)".

## الاتصال

1. ركّب المحوّل في السيارة، وشغّل الإشعال، ووصّل الكابل بالحاسوب.
2. في صفحة **اتصل** اختر **منفذ USB أو COM**.
3. اترك المنفذ على **البحث التلقائي** أو اختره من القائمة، ثم اتصل.

يجرّب البحث التلقائي كل منفذ تسلسلي بالسرعات المعتادة. إذا كنت تعرف سرعة محوّلك، يمكنك ضبطها في الإعدادات تحت **معدل باود للمحوّل**.

## Linux وmacOS

على Linux يظهر المحوّل باسم `/dev/ttyUSB0` أو `/dev/ttyACM0`. يجب أن يكون مستخدمك في المجموعة `dialout` (راجع [التثبيت](install.md)). على macOS يظهر باسم `/dev/cu.usbserial-...` أو `/dev/cu.wchusbserial...`.

## مشكلات شائعة

- **لا يظهر أي منفذ**: التعريف مفقود أو الكابل للشحن فقط.
- **المحوّل يجيب والسيارة لا**: الإشعال مطفأ، أو المحوّل نسخة مقلّدة لا تتعامل مع بروتوكول السيارة. [اختبار المحوّل](interfaces.md) يخبرك بالمزيد.
- **قيم مباشرة بطيئة جدًا في السيارات القديمة**: خط K-Line نفسه بطيء، وهذا ليس ذنب المحوّل.
