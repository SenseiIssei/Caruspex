# SAE J2534 PassThru

J2534 est l'interface standard des appareils de diagnostic professionnels sous Windows : Tactrix OpenPort 2.0, Drew Technologies Mongoose, VCX Nano, Scanmatik, Godiag, VAS 5054A en mode J2534 et bien d'autres. Chacun est livré avec une DLL de pilote de son fabricant, et Caruspex utilise ce pilote.

## Connexion

1. Installez le pilote du fabricant. Il s'enregistre dans Windows, et Caruspex le trouve là.
2. Sur la page **Connecter**, choisissez **Interface CAN**, sélectionnez l'appareil dans la liste et le débit (500 kbit/s pour l'OBD sur CAN).
3. Connectez. La tension de batterie de l'appareil s'affiche quand il peut la mesurer.

## Ce qui fonctionne

- **CAN** : Caruspex reçoit les trames CAN nues et gère lui-même l'ISO-TP, donc l'OBD, tous les calculateurs via UDS et la recherche rapide en parallèle des calculateurs fonctionnent.
- **VW TP 2.0** : tous les calculateurs de VW, Audi, Seat et Skoda d'environ 2004 à 2012, qu'un ELM327 ne peut pas atteindre.
- **K-Line** (ISO 9141 et 14230) : les pages KKL listent aussi les appareils J2534, pour les voitures plus anciennes.
- **CAN FD** avec les appareils qui le gèrent : cochez la case CAN FD sur la page Connecter.

## Anciens pilotes 32 bits

Beaucoup d'appareils anciens n'ont qu'un pilote 32 bits. Caruspex lance alors son petit programme auxiliaire `caruspex-j2534-bridge.exe`, qui se trouve à côté de `caruspex.exe`, y charge le pilote et transmet chaque appel par un tube local. La liste des appareils indique ces pilotes comme utilisables.

## Limites

- Windows uniquement, comme J2534 lui-même.
- Pas encore testé avec un vrai appareil J2534 : les tests tournent avec un faux pilote qui se comporte comme un vrai.

## Ligne de commande

```
caruspex_cli interfaces
caruspex_cli read --can "j2534:<name of the device>@500000"
```

`caruspex_cli interfaces` affiche les noms exacts.
