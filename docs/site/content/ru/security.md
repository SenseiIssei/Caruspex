# Безопасность и обновления

На этой странице собраны сведения о безопасности Caruspex: для чего нужна программа, какие риски стоит знать, как
работают обновления и как её удалить. Она следует информации для пользователей, которую требует европейский закон
о киберустойчивости (Cyber Resilience Act, приложение II), насколько она применима к свободной некоммерческой программе.

## Программа

- **Название**: Caruspex, приложение `caruspex` и инструмент командной строки `caruspex_cli` для Windows, Linux и
  macOS. Версия указана в имени каждого файла загрузки и в списке изменений каждого выпуска.
- **Издатель**: проект Caruspex на [GitHub](https://github.com/SenseiIssei/Caruspex), свободная программа под
  лицензией MIT. Вопросы и ошибки направляйте в [issues](https://github.com/SenseiIssei/Caruspex/issues).
- **Назначение**: чтение и объяснение диагностических данных автомобилей, мотоциклов и грузовиков через собственный
  адаптер на собственном компьютере. Без учётной записи, без облака и без слежки ([Конфиденциальность](privacy.md)).
- **Свойства безопасности**: чтение никогда ничего не меняет в автомобиле, а всё, что заставляет автомобиль что-то
  сделать, сначала спрашивает. Обновление устанавливается, только если его подпись совпадает с ключом, встроенным в
  приложение. Caruspex не открывает сетевых портов и не выполняет код из файлов или из интернета.

## Сообщить об уязвимости {#report}

Сообщайте о проблемах безопасности конфиденциально через
[форму нового уведомления о безопасности](https://github.com/SenseiIssei/Caruspex/security/advisories/new), а не в
открытом issue. [Политика безопасности](https://github.com/SenseiIssei/Caruspex/blob/main/SECURITY.md) описывает, что
будет дальше. Исправленные уязвимости публикуются как
[уведомления о безопасности](https://github.com/SenseiIssei/Caruspex/security/advisories).

## Риски, о которых стоит знать {#risks}

- Скачивайте Caruspex только со [страницы выпусков](https://github.com/SenseiIssei/Caruspex/releases). Копии из
  других мест могут быть изменены.
- Открывайте записи, пакеты PID и 3D-модели только от людей, которым доверяете. Они не могут выполнить код, но
  повреждённый файл может замедлить или закрыть Caruspex.
- Стирайте коды неисправностей, запускайте тесты исполнительных механизмов и базовые настройки только на стоящем
  автомобиле в безопасном месте.
- У многих адаптеров Bluetooth и Wi-Fi нет PIN-кода или открытая сеть: подключиться может любой поблизости. После
  работы отключайте адаптер.
- Кабели ENET, DoIP и адаптеры Wi-Fi ничего не шифруют: используйте их напрямую или только в своей сети.
- Драйверы J2534 являются программами их производителей и работают с вашими правами. Устанавливайте их только от
  производителя.

## Обновления и поддержка {#support}

- При каждой установке, в том числе после обновления со старой версии, Caruspex один раз спрашивает "Искать обновления?". Только после ответа "да" он спрашивает у GitHub, есть ли новая версия, при запуске и затем каждые шесть часов, пока работает. Новая версия лишь подсвечивает кнопку в заголовке окна и никогда не отвлекает. Установка занимает один щелчок, и приложение устанавливает только пакет с правильной подписью. AppImage и приложение для macOS обновляются сами; пакет .deb и приложение для Android получают страницу загрузки.
- Поиск и автоматическая установка включаются переключателями в настройках, в разделе **Окно и язык**, и их можно менять в любой момент. Без "да" запросы в GitHub не уходят; тогда время от времени заглядывайте на страницу выпусков.
- Исправления безопасности выходят только в новейшем выпуске. Старые версии отдельных исправлений не получают,
  поэтому обновляйте Caruspex.
- Caruspex ведёт один человек в свободное время, насколько позволяет время и без каких-либо обещаний: без срока поддержки и без сроков ответа. Если поддержка прекратится, репозиторий будет заархивирован и скажет об этом.

## Проверка загрузки {#verify}

В каждом выпуске есть файл `SHA256SUMS` с контрольной суммой каждого файла и подписанная GitHub запись о том, как
были собраны файлы. С файлами в одной папке:

```
sha256sum --ignore-missing -c SHA256SUMS
gh attestation verify Caruspex-<version>-windows-x64-setup.exe --repo SenseiIssei/Caruspex
```

Без этих инструментов `Get-FileHash <файл>` в PowerShell (Windows) или `shasum -a 256 <файл>` (macOS) покажет сумму
для сравнения со строкой в `SHA256SUMS`.

## Удаление Caruspex и своих данных {#remove}

1. Удалите программу: в Windows в Параметрах, Приложения; в macOS перетащите Caruspex из Программ; в Linux удалите
   AppImage или выполните `sudo apt remove caruspex`.
2. Удалите данные: кнопка **Открыть место хранения** в настройках показывает папки с настройками, гаражом и отчётами
   о сбоях. Удалите их. Записи и отчёты, которые вы сохранили сами, находятся там, где вы их сохранили.

## Для разработчиков и компаний {#integrators}

- В каждом выпуске для каждой платформы есть перечень программных компонентов
  `Caruspex-<version>-sbom-<platform>.cdx.json` (CycloneDX) с каждой библиотекой и её версией.
- Оценка рисков, список требований и сфера действия Cyber Resilience Act для Caruspex находятся в
  [docs/cra](https://github.com/SenseiIssei/Caruspex/tree/main/docs/cra).
- Caruspex не выводится на рынок как продукт в смысле Cyber Resilience Act, поэтому декларации соответствия ЕС и
  маркировки CE нет.
