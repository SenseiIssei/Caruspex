# DoIP (диагностика по IP)

Многие автомобили примерно с 2016 года можно диагностировать по Ethernet согласно ISO 13400, это называется DoIP. DoIP-кабель соединяет разъём OBD с сетевым портом компьютера.

## Подключение

1. Вставьте кабель, включите зажигание и подождите, пока компьютер получит автоматический адрес (169.254.x.x), это может занять до минуты.
2. На странице **Подключиться** выберите **Сетевой кабель** и оставьте поле пустым. Caruspex ищет в сети DoIP-автомобили и сам определяет, говорит машина по DoIP или по HSFZ от BMW.

## Что работает

OBD по DoIP и те блоки управления по UDS, адреса которых Caruspex знает для этой марки. Списки адресов для DoIP-машин пока короткие; их пополняют записи с настоящих автомобилей (что содержит отправленная запись, см. [конфиденциальность](privacy.md)).

## Какой кабель?

Для DoIP нужны линии Ethernet на контактах 3, 11, 12 и 13 разъёма OBD и линия активации на контакте 8. Кабели, которые продаются для определённой марки, обычно разведены именно так; кабель BMW ENET один из них.

## Командная строка

```
caruspex_cli enet
```

выводит список найденных в сети автомобилей BMW и DoIP.
