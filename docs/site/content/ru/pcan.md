# PEAK PCAN (Windows)

CAN-адаптеры PEAK-System (PCAN-USB, PCAN-USB FD, PCAN-USB Pro и другие) можно использовать в Windows напрямую, без драйвера J2534. В Linux это интерфейсы [SocketCAN](socketcan.md).

## Подключение

1. Установите драйвер устройства от PEAK. Он приносит библиотеку `PCANBasic.dll`, которую загружает Caruspex.
2. На странице **Подключиться** выберите **CAN-интерфейс**. Каждый канал PCAN с подключённым устройством сам появляется в списке; каналы, которые уже заняты другой программой, не показываются.
3. Выберите скорость (500 кбит/с для OBD по CAN) и подключитесь.

## Что работает

OBD, все блоки управления по UDS, параллельный поиск блоков, VW TP 2.0 и прослушивание широковещательных значений. CAN FD через PCAN-Basic пока не встроен.

## Командная строка

```
caruspex_cli read --can pcan:USB1@500000
```
