# SLCAN (Lawicel)

SLCAN: простой текстовый протокол поверх последовательного порта для CAN-адаптеров: CANable с прошивкой slcan, USBtin, Lawicel CANUSB и множество самодельных устройств. Работает в Windows, Linux и macOS.

## Подключение

1. Подключите адаптер к компьютеру, а кабелем к разъёму OBD: CAN high на контакт 6, CAN low на контакт 14, масса на контакты 4 и 5.
2. На странице **Подключиться** выберите **CAN-интерфейс**. SLCAN-адаптеры находит автоматический поиск портов, и они появляются в списке.
3. Выберите скорость (500 кбит/с для OBD по CAN) и подключитесь.

## Что работает

Как у любого прямого CAN-интерфейса: OBD, все блоки управления по UDS, параллельный поиск блоков, VW TP 2.0 и прослушивание широковещательных значений. CAN FD по SLCAN невозможен.

## Советы

- CANable с прошивкой candleLight не является SLCAN-устройством: в Linux он появляется как интерфейс [SocketCAN](socketcan.md).
- Адаптеру не нужен оконечный резистор на разъёме OBD, у машины есть свой.

## Командная строка

```
caruspex_cli read --can slcan:COM5@500000
caruspex_cli read --can slcan:/dev/ttyACM0@500000
```
