# ELM327 по USB

Адаптер для разъёма OBD с кабелем к порту USB. Это самый надёжный вариант ELM327: без сопряжения, без радиосвязи, без севших батареек.

## Драйвер

Внутри адаптера стоит USB-чип, который превращает кабель в последовательный порт (COM-порт в Windows). Какой драйвер нужен, зависит от этого чипа:

| Чип | Драйвер |
|---|---|
| FTDI FT232 | обычно Windows ставит сам, в Linux и macOS уже встроен |
| CH340 / CH341 | обычно Windows ставит сам, в Linux и macOS уже встроен |
| Silicon Labs CP210x | с сайта производителя, если Windows его не находит |
| Prolific PL2303 | с сайта производителя; старые клоны часто работают только со старым драйвером |

После подключения Диспетчер устройств Windows показывает адаптер в разделе "Порты (COM и LPT)".

## Подключение

1. Вставьте адаптер в разъём автомобиля, включите зажигание, подключите кабель к компьютеру.
2. На странице **Подключиться** выберите **USB или COM-порт**.
3. Оставьте порт на **Искать автоматически** или выберите его из списка, затем подключитесь.

Автоматический поиск пробует каждый последовательный порт на обычных скоростях. Если вы знаете скорость своего адаптера, её можно задать в настройках в пункте **Скорость обмена адаптера**.

## Linux и macOS

В Linux адаптер появляется как `/dev/ttyUSB0` или `/dev/ttyACM0`. Ваш пользователь должен входить в группу `dialout` (см. [Установка](install.md)). В macOS он появляется как `/dev/cu.usbserial-...` или `/dev/cu.wchusbserial...`.

## Частые проблемы

- **Порт не появляется**: нет драйвера, или кабель годится только для зарядки.
- **Адаптер отвечает, машина нет**: зажигание выключено, или адаптер это клон, который не справляется с протоколом автомобиля. [Тест адаптера](interfaces.md) расскажет больше.
- **Очень медленные текущие значения на старых машинах**: сама K-Line медленная, адаптер тут ни при чём.
