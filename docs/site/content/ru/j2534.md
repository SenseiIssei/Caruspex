# SAE J2534 PassThru

J2534: стандартный интерфейс профессиональных диагностических устройств в Windows: Tactrix OpenPort 2.0, Drew Technologies Mongoose, VCX Nano, Scanmatik, Godiag, VAS 5054A в режиме J2534 и многие другие. Каждое поставляется с DLL-драйвером от производителя, и Caruspex пользуется этим драйвером.

## Подключение

1. Установите драйвер производителя. Он сам регистрируется в Windows, и Caruspex находит его там.
2. На странице **Подключиться** выберите **CAN-интерфейс**, выберите устройство из списка и скорость (500 кбит/с для OBD по CAN).
3. Подключитесь. Напряжение аккумулятора показывается, если устройство умеет его измерять.

## Что работает

- **CAN**: Caruspex получает голые CAN-кадры и сам ведёт ISO-TP, так что работают OBD, все блоки управления по UDS и быстрый параллельный поиск блоков.
- **VW TP 2.0**: все блоки управления VW, Audi, Seat и Skoda примерно с 2004 по 2012 год, до которых ELM327 не достаёт.
- **K-Line** (ISO 9141 и 14230): страницы KKL тоже показывают устройства J2534, для старых машин.
- **CAN FD** с устройствами, которые его поддерживают: включите флажок CAN FD на странице подключения.

## Старые 32-битные драйверы

У многих старых устройств есть только 32-битный драйвер. Тогда Caruspex запускает свою маленькую вспомогательную программу `caruspex-j2534-bridge.exe`, которая лежит рядом с `caruspex.exe`, загружает драйвер в ней и передаёт каждый вызов по локальному каналу. В списке устройств такие драйверы отмечены как пригодные.

## Ограничения

- Только Windows, как и сам J2534.
- Ещё не проверено с настоящим устройством J2534: тесты идут на поддельном драйвере, который ведёт себя как настоящий.

## Командная строка

```
caruspex_cli interfaces
caruspex_cli read --can "j2534:<name of the device>@500000"
```

`caruspex_cli interfaces` выводит точные имена.
