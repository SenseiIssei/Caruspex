# Установка

Каждый выпуск лежит на [странице выпусков на GitHub](https://github.com/SenseiIssei/Caruspex/releases/latest). Пакеты пока не подписаны, поэтому Windows и macOS один раз переспросят перед первым запуском.

## Windows 10 и 11

| Файл | Что это |
|---|---|
| `Caruspex-<version>-windows-x64-setup.exe` | Установщик. Ему не нужны права администратора, он может добавить консольную утилиту `caruspex_cli` в путь поиска и устанавливает среду WebView2, только если её нет. |
| `Caruspex-<version>-windows-x64.zip` | Портативная версия: распакуйте и запустите `caruspex.exe`. |

При первом запуске Windows SmartScreen может сообщить, что приложение неизвестно: нажмите "Подробнее", затем "Выполнить в любом случае".

USB-адаптерам нужен драйвер для их USB-чипа. Windows 10 и 11 обычно находят его сами; если нет, смотрите [ELM327 по USB](elm327-usb.md).

## macOS 13 и новее (Apple Silicon)

Скачайте `Caruspex-<version>-macos.dmg`, откройте его и перетащите Caruspex в папку "Программы". Так как приложение ещё не нотаризовано, в первый раз откройте его правым щелчком и пунктом "Открыть".

## Linux (x86_64)

| Файл | Что это |
|---|---|
| `Caruspex-<version>-linux-x86_64.AppImage` | Работает почти на любом дистрибутиве: сделайте файл исполняемым через `chmod +x` и запустите. Он также обновляется сам. |
| `Caruspex-<version>-linux-amd64.deb` | Для Debian и Ubuntu: `sudo apt install ./Caruspex-<version>-linux-amd64.deb` |

Чтобы пользоваться последовательными адаптерами без `sudo`, один раз добавьте себя в группу `dialout`, затем выйдите из системы и войдите снова:

```
sudo usermod -aG dialout $USER
```

## Только консольная утилита

Для скриптов и серверов есть `caruspex_cli` без интерфейса, для Windows, Linux и macOS. `caruspex_cli help` выводит список команд.

`caruspex_cli report` записывает диагностический отчёт в файл PDF, без приложения и через любое подключение, которое знают остальные команды (`--demo`, `--port`, `--tcp`, `--enet`, `--can`, `--replay`):

```
caruspex_cli report --demo report.pdf
caruspex_cli report --port COM5 --lang de report.pdf
```

Отчёт бывает на немецком, английском, испанском, французском, португальском, итальянском, нидерландском и индонезийском (`--lang`). Для остальных языков, в том числе русского, он выходит на английском: в шрифтах, встроенных в любую программу просмотра PDF, нет их букв.

## Обновления

При каждой установке Caruspex один раз спрашивает, искать ли обновления. Только после ответа "да" он спрашивает у GitHub, есть ли новая версия, и больше ничего. Новая версия устанавливается, только если её подпись совпадает с ключом, встроенным в приложение. Проверку и автоматическую установку можно менять в настройках в любой момент.

## Менеджеры пакетов

Пакеты для winget, Homebrew, Flathub и Snap готовятся. Пока они не опубликованы, Caruspex устанавливается из файлов выше.
