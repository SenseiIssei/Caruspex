# Kvaser (Windows)

CAN-адаптеры Kvaser (Leaf, U100, Memorator и другие) можно использовать в Windows напрямую через библиотеку Kvaser CANlib. В Linux это интерфейсы [SocketCAN](socketcan.md).

## Подключение

1. Установите драйверы Kvaser. Они приносят `canlib32.dll`, которую загружает Caruspex.
2. На странице **Подключиться** выберите **CAN-интерфейс**. Каждый канал Kvaser с подключённым устройством появляется в списке; виртуальные каналы драйвера не показываются.
3. Выберите скорость (500 кбит/с для OBD по CAN) и подключитесь.

## Что работает

OBD, все блоки управления по UDS, параллельный поиск блоков, VW TP 2.0 и прослушивание широковещательных значений. CAN FD через CANlib пока не встроен.

## Командная строка

```
caruspex_cli read --can kvaser:0@500000
```
