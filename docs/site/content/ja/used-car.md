# 中古車チェック

買う前の現車確認のためのページです。ノートパソコンとアダプターを持って行って差し込めば、**中古車** ページが、売り手には簡単に隠せないことをチェックします。

![中古車チェック](screenshot-used-car.png)

## チェックする内容

- **VIN**：コントロールユニットの中の VIN は、車検証やカタログのものと一致しているか？
- **走行距離**：いくつものコントロールユニットにある走行距離の記録はそろっているか？
- **最近消去された？** 故障メモリーが最後に消去されてからの距離と時間。現車確認の直前に消されていたら、警戒のサインです。
- **レディネスモニター**：すべて完了しているか、それともリセットされたか？
- **記録されている故障**と **状態チェック**。
- 電気自動車では **バッテリーの状態**（劣化状態、セル）。車が報告する場合に限ります。

## 結果

信号機の表示、売り手に聞くべき質問、そして購入時に使える PDF。

## 知っておきたいこと

- イグニッションをオンにします。エンジンはかかっていても構いません。エンジンが冷えていると、一部のテストは未完了のままになります。
- 問題なしという結果は保証ではありません：OBD が見るのは電子系で、サビ、事故の損傷、機械部分の摩耗は分かりません。整備工場にも車を見てもらいましょう。
- 何かを差し込む前に、売り手に一声かけてください。
