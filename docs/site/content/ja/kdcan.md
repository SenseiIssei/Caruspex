# K+DCAN ケーブル

K+DCAN ケーブルは、1998 年から 2017 年ごろの BMW を整備工場用ソフト INPA や ISTA で診断するときの定番ケーブルです。中には FTDI のシリアルチップと、BMW の D-CAN 用の小さな変換器が入っています。こうしたケーブルの多くには、古い車用に 7 番ピンと 8 番ピンの間のスイッチかブリッジがあります。

## Caruspex での現状

> 正直な現状：Caruspex はこのケーブルの K-Line で BMW E シリーズを読み取ります。古いモデルは DS2、E60 世代は BMW 流の KWP2000 と BMW-FAST です。今のところプログラム内のシミュレーション車でしかテストしておらず、実際の BMW ではまだです。ケーブルの D-CAN モードにはまだ対応していません。

## K-Line モードで

- ケーブルをソケットに差し込む前に**スイッチを K-Line に**します。多くのケーブルでは左側の位置です。7 番と 8 番ピンをつなぐので、古いモデルの 8 番ピンにある制御ユニットも応答します。
- **対象の車**：E36（20 ピンの丸型プラグを変換アダプター経由で）、E38、E39、E46、E52、E53、E83、E85、そして 2007 年 3 月までの E60 世代（E60、E61、E63、E64、E65、E87、E90）。それ以降と F シリーズからは、ソケットは D-CAN かイーサネットを使います。
- **使い方**：プロモードをオンにし、「K-Line で BMW」ページでポートを選んで*スキャン*します。Caruspex は既知のアドレスすべてに DS2（9600 ボー、偶数パリティ）、KWP2000（高速初期化付き 10400 ボー）、BMW-FAST（115200 ボー）で問い合わせ、見つかった制御ユニットを識別情報と故障メモリーとともに表示します。30 秒ほどかかります。
- **消去**は制御ユニットごとにも全体でもでき、どちらも確認のあとだけです。その後 Caruspex は残ったものを読み直します。
- **故障コード**：BMW はコードの説明文を公開していないので、Caruspex は 16 進数で表示します。
- **読み取り専用**：コーディング、適合、アクチュエーターテストはありません。それは整備用ソフトの仕事です。
- **KKL ケーブル**も同じように使えますが、古いモデルでは 7 番と 8 番ピンがつながっていない限り、7 番ピンの制御ユニットにしか届きません。

車がなくても試せるように、ページのポート一覧にはシミュレーションの E46（DS2）と E60（KWP2000）があります。

## ほかに使えるもの

- **F シリーズ以降の BMW と Mini（2008 年ごろ以降）**：[ENET ケーブル](enet.md)ならイーサネットですべてのコントロールユニットに届きます。または普通の [ELM327](elm327-usb.md) で、CAN 上の BMW 独自のアドレス指定を使います。
- **CAN のある BMW での標準 OBD（2007 年ごろ以降）**：どの ELM327 でもエンジンの故障とライブ値が読めます。
