# K+DCAN ケーブル

K+DCAN ケーブルは、1998 年から 2017 年ごろの BMW を整備工場用ソフト INPA や ISTA で診断するときの定番ケーブルです。中には FTDI のシリアルチップと、BMW の D-CAN 用の小さな変換器が入っています。こうしたケーブルの多くには、古い車用に 7 番ピンと 8 番ピンの間のスイッチかブリッジがあります。

## Caruspex での現状

> 正直な現状：Caruspex は、このケーブルの D-CAN モードにはまだ対応していません。K-Line 経由の古い BMW プロトコル（DS2 と BMW 独自スタイルの KWP2000）は予定していますが、まず実車でのテストが必要です。

今のところ、代わりに使えるもの：

- **F シリーズ以降の BMW と Mini（2008 年ごろ以降）**：[ENET ケーブル](enet.md)ならイーサネットですべてのコントロールユニットに届きます。または普通の [ELM327](elm327-usb.md) で、CAN 上の BMW 独自のアドレス指定を使います。
- **CAN のある BMW での標準 OBD（2007 年ごろ以降）**：どの ELM327 でもエンジンの故障とライブ値が読めます。
- **K-Line モードでは**、このケーブルは [KKL ケーブル](kkl.md)と同じように K-Line をそのまま通します。VW グループの車には便利ですが、K-Line 上の BMW のコントロールユニットには、まだないプロトコルが必要です。
