# SAE J2534 PassThru

J2534 は、Windows でプロ向け診断機を使うための標準インターフェースです：Tactrix OpenPort 2.0、Drew Technologies Mongoose、VCX Nano、Scanmatik、Godiag、J2534 モードの VAS 5054A など多数。どれにもメーカー製のドライバー DLL が付いていて、Caruspex はそのドライバーを使います。

## 接続

1. メーカーのドライバーをインストールします。ドライバーは Windows に自分を登録し、Caruspex はそこから見つけます。
2. **接続** ページで **CAN インターフェース**を選び、一覧からデバイスを選んで、ビットレート（CAN 上の OBD なら 500 kbit/s）を選びます。
3. 接続します。デバイスが測れる場合は、バッテリー電圧が表示されます。

## できること

- **CAN**：Caruspex がむき出しの CAN フレームを受け取り、ISO-TP を自分で処理するので、OBD、UDS によるすべてのコントロールユニット、コントロールユニットの高速な並列検索が使えます。
- **VW TP 2.0**：2004 年から 2012 年ごろの VW、Audi、Seat、Skoda のすべてのコントロールユニット。ELM327 では届きません。
- **K-Line**（ISO 9141 と 14230）：古い車向けに、KKL のページにも J2534 デバイスが表示されます。
- **CAN FD**（対応デバイスのみ）：接続ページで CAN FD のチェックをオンにします。

## 古い 32 ビットドライバー

古いデバイスの多くには 32 ビットのドライバーしかありません。その場合、Caruspex は `caruspex.exe` の隣にある小さなヘルパープログラム `caruspex-j2534-bridge.exe` を起動し、そこでドライバーを読み込んで、すべての呼び出しをローカルのパイプ経由で渡します。デバイスの一覧では、そうしたドライバーも使用可能と表示されます。

## 制限

- J2534 自体と同じく、Windows のみ。
- まだ本物の J2534 デバイスではテストしていません：テストは、本物と同じように振る舞う偽のドライバーで行っています。

## コマンドライン

```
caruspex_cli interfaces
caruspex_cli read --can "j2534:<name of the device>@500000"
```

`caruspex_cli interfaces` で正確な名前が表示されます。
