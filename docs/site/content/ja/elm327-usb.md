# USB 接続の ELM327

OBD コネクターに差すプラグで、ケーブルで USB ポートにつなぎます。いちばん確実なタイプの ELM327 です：ペアリング不要、電波の心配なし、電池切れもありません。

## ドライバー

プラグの中の USB チップが、ケーブルをシリアルポート（Windows では COM ポート）に変えます。必要なドライバーはそのチップによって決まります：

| チップ | ドライバー |
|---|---|
| FTDI FT232 | Windows がたいてい自動でインストール、Linux と macOS は標準搭載 |
| CH340 / CH341 | Windows がたいてい自動でインストール、Linux と macOS は標準搭載 |
| Silicon Labs CP210x | Windows が見つけられない場合はメーカーのサイトから |
| Prolific PL2303 | メーカーのサイトから。古いコピー品は古いドライバーでしか動かないことが多い |

差し込んだあと、Windows のデバイスマネージャーの「ポート (COM と LPT)」にアダプターが表示されます。

## 接続

1. アダプターを車に差し、イグニッションをオンにしてから、ケーブルをパソコンに差します。
2. **接続** ページで **USB または COM ポート**を選びます。
3. ポートは **自動で検索**のままにするか、一覧から選んで、接続します。

自動検索は、すべてのシリアルポートを一般的な速度で試します。アダプターの速度が分かっていれば、設定の **アダプターのボーレート**で指定できます。

## Linux と macOS

Linux ではアダプターは `/dev/ttyUSB0` か `/dev/ttyACM0` として表示されます。ユーザーが `dialout` グループに入っている必要があります（[インストール](install.md)を参照）。macOS では `/dev/cu.usbserial-...` か `/dev/cu.wchusbserial...` として表示されます。

## よくあるトラブル

- **ポートが表示されない**：ドライバーがないか、ケーブルが充電専用です。
- **アダプターは応答するのに車が応答しない**：イグニッションがオフか、アダプターがその車のプロトコルに対応していないコピー品です。[アダプターのテスト](interfaces.md)で詳しく分かります。
- **古い車でライブ値がとても遅い**：K-Line 自体が遅いためで、アダプターのせいではありません。
