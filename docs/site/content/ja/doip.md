# DoIP（Diagnostics over IP）

2016 年ごろ以降の多くの車は、ISO 13400 に従ってイーサネット経由で診断できます。これが DoIP です。DoIP ケーブルは、OBD コネクターとパソコンの LAN ポートをつなぎます。

## 接続

1. ケーブルを差し、イグニッションをオンにして、パソコンに自動アドレス（169.254.x.x）が割り当てられるまで待ちます。最大で 1 分ほどかかります。
2. **接続** ページで **ネットワークケーブル**を選び、入力欄は空のままにします。Caruspex がネットワーク上の DoIP 車両を探し、その車が DoIP を話すのか BMW の HSFZ を話すのかを自動で見分けます。

## できること

DoIP 経由の OBD と、Caruspex がそのブランドのアドレスを知っているコントロールユニットへの UDS でのアクセス。DoIP 車両のアドレス一覧はまだ短く、実車の記録で埋まっていきます（共有した記録に何が含まれるかは[プライバシー](privacy.md)を参照）。

## どのケーブル？

DoIP には、OBD コネクターの 3、11、12、13 番ピンのイーサネット線と、8 番ピンのアクティベーション線が必要です。特定のブランド向けに売られているケーブルは、たいていまさにそのように配線されています。BMW の ENET ケーブルもその 1 つです。

## コマンドライン

```
caruspex_cli enet
```

ネットワーク上で見つかった BMW と DoIP の車両を一覧表示します。
