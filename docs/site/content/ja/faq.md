# よくある質問

## Caruspex はお金がかかりますか？

かかりません。Caruspex は MIT ライセンスのフリーソフトウェアで、広告もアカウントも有料の追加機能もありません。

## どのアダプターを買えばいいですか？

ほとんどの人には、FTDI か CH340 チップの USB 接続 ELM327、または OBDLink（Bluetooth か USB）が最初の一台としていちばんです。2004 年ごろより前の VW、Audi、Seat、Skoda には [KKL ケーブル](kkl.md)を、F シリーズ以降の BMW と Mini には [ENET ケーブル](enet.md)を追加してください。[インターフェースの一覧](interfaces.md)で比較しています。

## 自分の車で使えますか？

OBD-II か EOBD のある車なら、エンジンについては使えます：ヨーロッパでは 2001 年以降のガソリン車と 2004 年以降のディーゼル車、アメリカでは 1996 年以降の車です。1990 年ごろ以降の古い VW グループの車は KKL ケーブルで使えます。ある車でどの方法が使えるかは **車両** ページで分かります。Euro 5 以降のバイクは、診断プラグ用の変換ケーブルがあれば使えます。

## 自分の車でテストされていますか？

正直に言うと、まだです。Caruspex はシミュレーションしたコントロールユニットでテストしています。実際のハードウェアで確認できたのは、今のところ STN2232 チップの OBDLink 1 台だけで、それも車にはつないでいません。[テストレポート](https://github.com/SenseiIssei/Caruspex/issues/new?template=test-report.yml)でぜひ協力してください。

## Caruspex で車が壊れることはありますか？

Caruspex は読み取るだけです。書き込むのは故障コードの消去だけで、その前に警告します。コーディングも、書き換えも、適応値の変更も一切しません。運転中には使わないでください。

## 走行距離やイモビライザーを変えたり、機能をコーディングしたりできますか？

できませんし、今後もしません。法的に微妙な問題で、このツールの目的でもありません。

## アダプターはバージョン 2.1 と言っているのに、うまくいかないことがあるのはなぜ？

安いアダプターの多くは、実際より新しい ELM327 のバージョンを名乗ります。**アダプターのテスト**で、そのアダプターが本当に分かるコマンドを調べられます。

## 古い車だと値が遅いのはなぜ？

K-Line の車（ヨーロッパではおよそ 2001 年から 2007 年）は、もともと応答が遅い仕組みです。CAN の車はずっと速いです。

## Caruspex は私のデータをどこかに送りますか？

送りません。アップデートの確認だけが GitHub に最新バージョンを問い合わせますが、これもオフにできます。[プライバシー](privacy.md)を参照してください。

## どうすれば協力できますか？

自分の車のテストレポートを送る、記録を共有する、バグを報告する、翻訳を改善する、などです。翻訳のガイドは [TRANSLATING.md](https://github.com/SenseiIssei/Caruspex/blob/main/translations/TRANSLATING.md) で、設定の **翻訳を改善** ボタンでも開けます。
