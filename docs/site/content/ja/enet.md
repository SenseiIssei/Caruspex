# BMW ENET ケーブル

F シリーズ以降（2008 年ごろ以降）の BMW と Mini は、OBD コネクターにイーサネットがあります。ENET ケーブルは OBD コネクターからパソコンの LAN ポートへ直接つなぐもので、間にアダプターのチップはありません。Caruspex は車のゲートウェイと HSFZ で通信し（ポート 6811 と 6801）、すべてのコントロールユニットにアクセスします。

## 接続

1. ケーブルを車とパソコンの LAN ポート（または USB の LAN アダプター）に差します。イグニッションをオンにします。
2. 最大 1 分待ちます：DHCP サーバーがない場合、Windows、macOS、Linux は自分でパソコンに自動アドレス（169.254.x.x）を割り当てます。
3. **接続** ページで **ネットワークケーブル**を選び、入力欄は空のままにします：Caruspex がネットワーク上の車を探します。見つからない場合は、車のアドレスを入力してください。

## できること

- BMW のアドレス指定による UDS で、すべてのコントロールユニットにアクセス。故障コードは ISTA と同じ BMW 形式で表示されます（例えば 480A10）。
- コントロールユニットごとの故障メモリー、識別情報、消去、OBD 経由のライブ値。
- ここでも Caruspex は読み取るだけです。コーディングや書き換えは整備工場用のソフトに任せます。

## どのケーブル？

普通の ENET ケーブルには、8 番ピンと 16 番ピンの間に抵抗が入っていて、それが車のイーサネットをオンにします。抵抗のないケーブルでは車は反応しません。1 Gbit/s の LAN ポートでも使えます。車は 100 Mbit/s で通信します。

## コマンドライン

```
caruspex_cli ecus --enet auto
```
