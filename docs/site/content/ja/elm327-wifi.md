# Wi-Fi 接続の ELM327

自分で Wi-Fi ネットワークを作るアダプターがあります。パソコンがそのネットワークに入り、TCP でアダプターとやりとりします。

## 接続

1. アダプターを差してイグニッションをオンにします。数秒で Wi-Fi ネットワークが現れます。名前はよく `WiFi_OBDII`、`V-LINK`、またはメーカー名です。
2. パソコンをそのネットワークにつなぎます。インターネットにはつながらないので、システムが「接続が制限されています」と警告するかもしれませんが、問題ありません。
3. Caruspex の **接続** ページで **Wi-Fi**を選びます。ほとんどのアダプターはアドレス `192.168.0.10` とポート `35000` を使い、これが初期設定になっています。別のアドレス（例えば `192.168.4.1`）を使うものなら、`address:port` の形で入力してください。

## ヒント

- パソコンがアダプターのネットワークにいる間は、インターネットは使えません。Caruspex には関係ありません。
- Wi-Fi アダプターはどのシステムでもドライバーなしで使えます。
- 接続が切れるときは、パソコンを車に近づけてください：こうしたプラグの電波は弱いです。
