# 故障

**故障メモリー** ページは、コントロールユニットに記録されている内容を読み取り、分かりやすい言葉で説明します。

![故障メモリー](screenshot-faults.png)

## 表示される内容

- **記録済み、保留中、恒久**の故障コード。複数のコントロールユニットがある場合、どのコードもどこが出したもの（エンジン、トランスミッション）かが分かります。
- 約 3,400 の標準コード（P、C、B、U）と、VAG、Ford、GM、Toyota、Honda、Nissan、Hyundai と Kia、Subaru などのメーカー独自コード。P1 コードは、検出したブランドでの意味どおりに読み取ります。
- コードごとの**信号機**表示と、誰もが最初に聞く質問への答え：このまま走っていい？
- よくある原因、自分で確認できること、おおよその費用クラス。
- 部品がどこにあるか：透けて見える車の図、または[透視ビュー](xray.md)。

## すべてのコントロールユニット

プロモードでは、**すべてのコントロールユニット** ページがエンジンだけでなく、すべてのコントロールユニットに問い合わせます：ABS、エアバッグ、メーター、エアコンなど。それぞれの故障には、故障の種類（短絡、断線、信号の異常）、部品番号、ソフトウェアのバージョンが付きます。古い VW グループの車は [KKL ケーブル](kkl.md)で読み取ります。

## いま何をすればいい？

**どうする？** ページは、Caruspex が見つけたものをすべて 3 段階に分けます：すぐ止まる、近いうちに整備工場へ、急がなくていい。どの項目にも、理由をひと言で説明する文、おおよその費用の幅、整備工場で見せるためのメモが付きます。エンジン警告灯が点滅しているか、赤い警告灯が点いているかは OBD では分からないので、2 つのチェック欄であなたに聞きます。警告灯が点滅していて失火がある場合、その項目は「すぐ止まる」に移ります。

![いま何をすればいい](screenshot-todo.png)

## コードの消去

消去はコントロールユニットごとに、はっきりした警告のうえで行えます。消去の直後に Caruspex がメモリーを読み直します。

> 消去は修理ではありません。レディネスモニターもリセットされます：車が何回か完全な走行サイクルを終えるまで排ガス検査に通りませんし、原因が残っているコードは少し走るとまた出てきます。
