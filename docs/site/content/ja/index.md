# Caruspex

Caruspex は、車とバイクのための無料の診断ソフトです。Windows、Linux、macOS で動き、18 言語に対応し、みんなが実際に持っているアダプターで使えます：安い ELM327 プラグ、OBDLink、古い Volkswagen グループ車用の KKL ケーブル、BMW 用の ENET ケーブル、そしてプロ向けの CAN インターフェースです。

![ライブメーター付きの概要画面](screenshot-overview.png)

## できること

- 故障コードを読み取って消去し、分かりやすい言葉で説明し、このまま走っていいかを教えます。
- ライブ値を表示します：温度、車速、混合気、過給圧、バッテリー電圧など多数を、数字とグラフで。
- 車とアダプターが許す範囲で、エンジンだけでなく車のすべてのコントロールユニットに問い合わせます。
- 中古車を買う前にチェックします：VIN は合っているか、走行距離はそろっているか、直前に故障が消されていないか。
- 車をガラスのモデルとして表示し、故障や値がそれぞれの場所で光ります。
- 次に何をすべきかを教えます：すぐ止まる、近いうちに整備工場へ、または急がなくていい。

## どこから始めるか

1. パソコンに [Caruspex をインストール](install.md)します。
2. [最初のステップ](first-steps.md)に沿って進みます：まずデモカーを試し、それから自分の車をつなぎます。
3. [アダプターとインターフェース](interfaces.md)で自分のアダプターを調べます。
4. Caruspex が何を保存し、何を送るかを[プライバシー](privacy.md)で読みます。要するに：あなたが自分で共有しない限り、何もパソコンの外には出ません。

> Caruspex は読み取るだけです。コントロールユニットのコーディングも、走行距離の変更も、イモビライザーへの手出しも一切しません。故障コードの消去だけが、車に書き込む唯一の操作です。

## 正直な現状

Caruspex は仕様書に従って作られ、シミュレーションしたコントロールユニット、偽のゲートウェイ、偽のドライバーでテストしています。実際のハードウェアで確認できたのは、今のところ STN2232 チップの OBDLink 1 台だけで、それも車にはつないでいません。自分の車で Caruspex を試したら、ぜひ[テストレポート](https://github.com/SenseiIssei/Caruspex/issues/new?template=test-report.yml)を送ってください：レポートが届くたびに、テスト済みの車の一覧が長くなります。
