# プライバシー

Caruspex はあなたのパソコンの中で動きます。アカウントも、クラウドも、トラッキングもありません。

## 保存されるもの

すべてあなたのパソコンに残ります：

| 何を | いつ | どこに |
|---|---|---|
| 設定 | 常に | システムの設定フォルダー（設定の **保存場所を開く** ボタンで表示できます） |
| ガレージ：VIN、車、チェック、走行距離の記録、最後にうまくいった接続方法 | 車をつないだあと | 設定の隣、Caruspex のデータフォルダーの中 |
| 記録と CSV ファイル | あなたが開始したときだけ | あなたが保存した場所 |
| ログファイル | 設定でオンにした場合だけ | あなたが選んだパス |
| クラッシュレポート | Caruspex がクラッシュした場合だけ | ガレージの隣の `crash-reports` フォルダー |

これらのファイルはいつでも削除できます。

## 送信されるもの

起動時に Caruspex は GitHub に新しいバージョンがあるかを問い合わせます。そのとき、あなたや車についての情報は何も送りません。この確認は設定でオフにできます。それ以外に Caruspex がインターネットにつなぐことはありません。Wi-Fi アダプター、ENET ケーブル、DoIP の車とのやりとりは、あなたのローカルネットワークの中だけで行われます。

## クラッシュレポートは希望したときだけ

Caruspex がクラッシュすると、短いレポートをあなたのパソコンに書き出します：バージョン、システム、コードの場所、呼び出しの流れ。VIN、車との通信のバイト、あなたのホームフォルダーは取り除かれます。何も送信しません。Caruspex はレポートを見せて、2 つのボタンを出します：**GitHub で報告**はブラウザーで入力済みの issue を開き、投稿の前に読んで書き換えられます。**報告しない**はレポートをしまいます。

## 個人データなしで記録を共有する

実車の記録は、Caruspex をもっと多くの車に対応させる助けになります。**記録を共有**はコピーを用意し、何が残って何が消えるかをはっきり見せます：

- **取り除くもの**：VIN の末尾の数桁（ファイル内のすべての箇所）、ポート名、アダプターの Bluetooth アドレスまたはネットワークアドレス、時刻。
- **記録に決して含まれないもの**：あなたの位置情報とユーザーデータ。
- **残るもの**：要求と応答、アダプターの種類、プロトコル、日付。

ファイルは、あなたが自分で保存して GitHub の issue に添付するまで、あなたのパソコンに残ります。自動でアップロードされるものは何もありません。

## テストプログラム

[テストレポートのフォーム](https://github.com/SenseiIssei/Caruspex/issues/new?template=test-report.yml)では、車、年式、エンジン、アダプターを聞きます。VIN は短くしたものだけを求めます。VIN 全体、ナンバープレート、名前は決して投稿しないでください。
