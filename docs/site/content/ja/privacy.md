# プライバシー

Caruspex はあなたのパソコンの中で動きます。アカウントも、クラウドも、トラッキングもありません。

## 保存されるもの

すべてあなたのパソコンに残ります：

| 何を | いつ | どこに |
|---|---|---|
| 設定 | 常に | システムの設定フォルダー（設定の **保存場所を開く** ボタンで表示できます） |
| ガレージ：VIN、車、チェック、走行距離の記録、最後にうまくいった接続方法 | 車をつないだあと | 設定の隣、Caruspex のデータフォルダーの中 |
| 記録と CSV ファイル | あなたが開始したときだけ | あなたが保存した場所 |
| ログファイル | 設定でオンにした場合だけ | あなたが選んだパス |
| クラッシュレポート | Caruspex がクラッシュした場合だけ | ガレージの隣の `crash-reports` フォルダー |
| KKL 初回テストのレポート | 保存したときだけ | 設定フォルダー内の `test-reports` フォルダー。チェックを入れない限り VIN とイモビライザー番号は短縮されます |

これらのファイルはいつでも削除できます。

## 送信されるもの

インストールのたびに、古いバージョンからアップデートした場合も、Caruspex は一度だけアップデートを確認してよいか尋ねます。「はい」と答えたあとにだけ、起動時と、動作中は 6 時間ごとに、新しいバージョンがあるか GitHub に問い合わせます。そのとき、あなたや車についての情報は何も送りません。「はい」と答えていなければ GitHub へのリクエストは一切送られません。これは設定の **ウィンドウと言語** でいつでも変更できます。それ以外に Caruspex がインターネットにつなぐことはありません。Wi-Fi アダプター、ENET ケーブル、DoIP の車とのやりとりは、あなたのローカルネットワークの中だけで行われます。

更新を確認するのは GitHub で公開されたリリース版だけで、自分でビルドしたものは確認しません。Caruspex が更新を確認したりダウンロードしたりするとき、ほかのダウンロードと同じく、GitHub にはコンピューターの IP アドレスと Caruspex のバージョンが伝わります。Caruspex 自身はそれ以外を送信も保存もせず、プロジェクトを含め、ほかの誰にもそれは見えません。これには GitHub のプライバシーに関する声明が適用されます。更新は Caruspex リポジトリのリリースからのみダウンロードされます。**GitHub で報告** などのボタンはブラウザーを開くだけで、そこで何を投稿するかはあなたが決めます。

## Android

Android 11 までは、位置情報の権限がないとアプリは Bluetooth LE アダプターを見つけられません。Caruspex はその理由だけでこの権限を求め、位置情報を読むことはありません。Android 12 以降は代わりに Bluetooth の権限を求め、位置情報には使わないことを宣言しています。

## クラッシュレポートは希望したときだけ

Caruspex がクラッシュすると、短いレポートをあなたのパソコンに書き出します：バージョン、システム、コードの場所、呼び出しの流れ。VIN、車との通信のバイト、あなたのホームフォルダーは取り除かれます。何も送信しません。Caruspex はレポートを見せて、2 つのボタンを出します：**GitHub で報告**はブラウザーで入力済みの issue を開き、投稿の前に読んで書き換えられます。**報告しない**はレポートをしまいます。

## 個人データなしで記録を共有する

実車の記録は、Caruspex をもっと多くの車に対応させる助けになります。**記録を共有**はコピーを用意し、何が残って何が消えるかをはっきり見せます：

- **取り除くもの**：VIN の末尾の数桁（ファイル内のすべての箇所）、ポート名、アダプターの Bluetooth アドレスまたはネットワークアドレス、時刻。
- **記録に決して含まれないもの**：あなたの位置情報とユーザーデータ。
- **残るもの**：要求と応答、アダプターの種類、プロトコル、日付。

ファイルは、あなたが自分で保存して GitHub の issue に添付するまで、あなたのパソコンに残ります。自動でアップロードされるものは何もありません。

## テストプログラム

[テストレポートのフォーム](https://github.com/SenseiIssei/Caruspex/issues/new?template=test-report.yml)では、車、年式、エンジン、アダプターを聞きます。VIN は短くしたものだけを求めます。VIN 全体、ナンバープレート、名前は決して投稿しないでください。
