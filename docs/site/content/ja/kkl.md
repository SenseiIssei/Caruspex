# KKL ケーブル（VAG 409.1）

KKL ケーブルは、シリアルチップと K-Line ドライバーが入った USB ケーブルで、中に ELM327 はありません。Caruspex が自分で K-Line を 1 バイトずつ動かします。古い VW、Audi、Seat、Skoda に必要なのはまさにこれです：これらの車のプロトコル KWP1281 は 1 バイトごとに確認応答を返し、それはどの ELM327 にもできません。

## できること

- 1990 年から 2004 年ごろの VW、Audi、Seat、Skoda のすべてのコントロールユニット：エンジン、トランスミッション、ABS、エアバッグ、メーター、快適装備など。
- KWP1281 と KWP2000（ISO 14230）。ウェイクアップ後のキーバイトから自動で判別します。
- コントロールユニットごとの故障メモリー、測定ブロック、そしてスロットルボディの本当の基本設定（測定ブロック 060 または 098）。
- 適応チャンネルは、あえて読み取り専用にしています。出力テストは実際の部品を動かすため、確認してから始まります。

これらのページは**プロモード**にあります：**KKL 経由のコントロールユニット**、**スロットルボディ**、**適応と出力テスト**。どのページも自分でケーブルを開きます：シリアルポートとコントロールユニットを選んで、開始します。

## どのケーブル？

本物の FTDI FT232RL か CP2102 のケーブルは、いちばん安いコピー品よりも K-Line でずっと確実です。KWP1281 には本物の FTDI をおすすめします。ケーブルは K-Line を加工せずそのまま通す必要があります：独自ファームウェアの「HEX-USB」インターフェースは使えません。

1996 年ごろより前の車には OBD コネクターがなく、エンジンルームかダッシュボードの下に 2x2 のプラグがあることがよくあります。2x2 から 16 ピンのコネクターへの変換アダプターは安く手に入ります。

## ケーブルのチェック

コマンドラインツールで、車なしでケーブルをテストできます：

```
caruspex_cli kklcheck --port COM3
```

## 実車での初回テスト

プロモードのページ **実車での初回テスト** は、新しい KKL ケーブルでの最初のセッションを案内します。Audi A2 向けに作っていて、K-Line のある VW、Audi、Seat、Skoda ならどれでも使えます。読み取りだけです：何も消去せず、出力テストも基本設定もしません。ポートはテストを始めたときにだけ開きます。

1. **車なしでケーブルをチェックします。** ケーブルは USB にだけ差し、そのポートを選んで **ケーブルをチェック** を押します。Caruspex はチップ（FTDI、CH340、Prolific、CP210x）と、FTDI ならレイテンシタイマーを読み取り、Break ライン上で 5 ボーアドレスのビットを測ります。車なしではエコーが返りませんが、それで正常です。
2. **レイテンシタイマーを 1 ms にします**（Windows の FTDI ケーブル）：デバイス マネージャー、ポート (COM と LPT)、USB Serial Port をダブルクリック、ポートの設定、詳細設定、Latency Timer (msec) を 1、OK、そのあとケーブルを一度抜いて差し直します。初期値の 16 ms のままだと、キーバイトへの返信が 50 ms の枠に間に合わないことがあります。Caruspex はこの設定を読み取りますが、変えることはありません。
3. **車で：** イグニッションをオン、エンジンは停止、ケーブルは OBD コネクターにしっかり差してパソコンに直接つなぎ（USB ハブなし）、ほかの診断プログラムは閉じておきます。チェックリストにチェックを入れて **初回テストを開始** を押します。
4. テストはエンジン（アドレス 01）を起こし、アドレスの各ビット、同期バイト 0x55、キーバイトとそれへの返信を測ります。続いて識別情報、故障メモリー、測定ブロック 001 から 003 を読み、そのあとメーターパネル 17、ABS 03、エアバッグ 15、コンフォート 46、セントラル電装 09 を読みます。応答しないユニットは、単に装着されていないだけかもしれません。
5. **レポートを保存** は、テキストファイルと JSON ファイルを Caruspex の設定フォルダー内の `test-reports` フォルダーに書き込みます。**GitHub でテストレポートを開く** は、レポートのフォームを代わりに埋めてくれます。チェックを入れない限り、VIN とイモビライザー番号は短縮されます。

結果の意味：

| 結果 | どうするか |
|---|---|
| エコーなし | ケーブルが自分の送信を受け取れません：プラグがきちんと入っていないか、16 番ピンに 12 V が来ていません（診断コネクターのヒューズを確認）。車なしならこれが正常です。 |
| エコーが化けています | コネクターに別の機器がつながっている、K+DCAN ケーブルのスイッチが K-Line になっていない、またはケーブルの故障です。 |
| ウェイクアップアドレスのタイミングが不正確すぎます | ビットが 200 ms から 20 ms 以上ずれています：USB ハブを使わない、ほかのプログラムを閉じる、レイテンシタイマーを 1 ms に。Caruspex は Break 呼び出しを前倒しにして、もう一度試します。 |
| ケーブルは OK、でも車から応答がありません | イグニッションはオンですか？ アドレス 01 はエンジンです。2005 年ごろ以降の車は CAN で診断します。 |
| キーバイトへの返信が遅すぎました | レイテンシタイマーを 1 ms にしてください。 |

## よくあるトラブル

- **コントロールユニットが応答しない**：イグニッションはオン？ 5 ボーのウェイクアップには正確なタイミングが必要です。USB ハブや一部の仮想マシンはそれを狂わせるので、ケーブルは直接つないでください。
- **しばらくすると切れる**：安いケーブルはバイトを取りこぼします。車を疑う前に、別のケーブルを試してください。
