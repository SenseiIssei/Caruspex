# ライブ値

**ライブ値** ページ（プロモード）は、センサーがいま測っている値を表示します。初心者モードでは、**ドライブモード**がいちばん大事な値を大きな文字で表示します。

![ライブ値](screenshot-live.png)

## 表示できるもの

- SAE J1979 のモード 01 の、PID C4 までのすべての値：145 の PID と 300 以上の測定値を、グループ分けして検索可能に。どれに対応しているかは車が自分で教えてくれます。
- 走行距離計、ギア、油温、燃料消費率、トルク、過給圧、排気温度、粒子フィルター、AdBlue、NOx、ハイブリッドバッテリー。車が報告する範囲で。
- 複数の値を同時に表示する流れるグラフ。長い時間幅（最大 1 時間）では古い点を間引きますが、山と谷はすべて残します。
- CSV への記録。

## メーカー独自の値と自分で追加する値

- **電気自動車のバッテリー**：劣化状態（SOH）、充電量、ばらつきを含むセル電圧、温度。対象は Hyundai Kona と Ioniq、Kia e-Niro、Renault Zoe、Nissan Leaf、Tesla Model 3 と Y（CAN バスの受信による）で、**EV バッテリー** ページにあります。
- **OBDb の値**：さらに約 550 車種分（タイヤ空気圧、オイル、走行距離計など）。検出した車に合わせて自動で表示されます。
- **自分で追加する値**：広く使われている Torque の CSV 形式で、計算式も含めて読み込めます。

![EV バッテリー](screenshot-battery.png)

## どのくらい速い？

1 秒あたりに届く値の数は、車とアダプターによって変わります。CAN の車は応答が速く、K-Line の車はもともと遅い仕組みです。OBDLink なら、Caruspex は一度に最大 24 個の値を要求できます（[OBDLink と STN](obdlink-stn.md) を参照）。生の CAN インターフェースがいちばん速い方法です。

## 記録と再生

車とのやりとりをまるごとファイルに記録し、あとで車なしで再生できます。トラブルの原因を探すときに便利です。**記録を共有**を使うと、個人データを含まない形で記録をプロジェクト向けに用意できます。[プライバシー](privacy.md)を参照してください。
