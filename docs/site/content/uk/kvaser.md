# Kvaser (Windows)

CAN-адаптери Kvaser (Leaf, U100, Memorator та інші) можна використовувати у Windows напряму через бібліотеку Kvaser CANlib. У Linux це інтерфейси [SocketCAN](socketcan.md).

## Підключення

1. Встановіть драйвери Kvaser. Вони приносять `canlib32.dll`, яку завантажує Caruspex.
2. На сторінці **Підключитися** виберіть **CAN-інтерфейс**. Кожен канал Kvaser із підключеним пристроєм з'являється в списку; віртуальні канали драйвера не показуються.
3. Виберіть швидкість (500 кбіт/с для OBD через CAN) і підключіться.

## Що працює

OBD, усі блоки керування через UDS, паралельний пошук блоків, VW TP 2.0 і прослуховування широкомовних значень. CAN FD через CANlib поки не вбудовано.

## Командний рядок

```
caruspex_cli read --can kvaser:0@500000
```
