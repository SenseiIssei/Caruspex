# ELM327 через USB

Адаптер для роз'єму OBD з кабелем до порту USB. Це найнадійніший варіант ELM327: без сполучення, без радіозв'язку, без розряджених батарейок.

## Драйвер

Усередині адаптера стоїть USB-чип, який перетворює кабель на послідовний порт (COM-порт у Windows). Який драйвер потрібен, залежить від цього чипа:

| Чип | Драйвер |
|---|---|
| FTDI FT232 | зазвичай Windows встановлює сам, у Linux і macOS уже вбудований |
| CH340 / CH341 | зазвичай Windows встановлює сам, у Linux і macOS уже вбудований |
| Silicon Labs CP210x | із сайту виробника, якщо Windows його не знаходить |
| Prolific PL2303 | із сайту виробника; старі клони часто працюють лише зі старим драйвером |

Після підключення Диспетчер пристроїв Windows показує адаптер у розділі "Порти (COM і LPT)".

## Підключення

1. Вставте адаптер у роз'єм авто, увімкніть запалювання, підключіть кабель до комп'ютера.
2. На сторінці **Підключитися** виберіть **USB або COM-порт**.
3. Залиште порт на **Шукати автоматично** або виберіть його зі списку, потім підключіться.

Автоматичний пошук пробує кожен послідовний порт на звичних швидкостях. Якщо ви знаєте швидкість свого адаптера, її можна задати в налаштуваннях у пункті **Швидкість адаптера (бод)**.

## Linux і macOS

У Linux адаптер з'являється як `/dev/ttyUSB0` або `/dev/ttyACM0`. Ваш користувач має бути в групі `dialout` (див. [Встановлення](install.md)). У macOS він з'являється як `/dev/cu.usbserial-...` або `/dev/cu.wchusbserial...`.

## Типові проблеми

- **Порт не з'являється**: немає драйвера, або кабель лише для заряджання.
- **Адаптер відповідає, авто ні**: запалювання вимкнено, або адаптер є клоном, який не справляється з протоколом авто. [Тест адаптера](interfaces.md) розповість більше.
- **Дуже повільні поточні значення на старих авто**: сама K-Line повільна, адаптер тут ні до чого.
