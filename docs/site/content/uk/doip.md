# DoIP (діагностика через IP)

Багато авто приблизно з 2016 року можна діагностувати через Ethernet згідно з ISO 13400, це називається DoIP. DoIP-кабель з'єднує роз'єм OBD із мережевим портом комп'ютера.

## Підключення

1. Вставте кабель, увімкніть запалювання і зачекайте, поки комп'ютер отримає автоматичну адресу (169.254.x.x), це може тривати до хвилини.
2. На сторінці **Підключитися** виберіть **Мережевий кабель** і залиште поле порожнім. Caruspex шукає в мережі DoIP-авто і сам визначає, чи розмовляє авто через DoIP, чи через HSFZ від BMW.

## Що працює

OBD через DoIP і ті блоки керування через UDS, адреси яких Caruspex знає для цієї марки. Списки адрес для DoIP-авто поки короткі; їх поповнюють записи зі справжніх авто (що містить надісланий запис, див. [конфіденційність](privacy.md)).

## Який кабель?

Для DoIP потрібні лінії Ethernet на контактах 3, 11, 12 і 13 роз'єму OBD і лінія активації на контакті 8. Кабелі, що продаються для певної марки, зазвичай розпаяні саме так; кабель BMW ENET один із них.

## Командний рядок

```
caruspex_cli enet
```

виводить список знайдених у мережі авто BMW і DoIP.
