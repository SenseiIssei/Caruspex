# PEAK PCAN (Windows)

CAN-адаптери PEAK-System (PCAN-USB, PCAN-USB FD, PCAN-USB Pro та інші) можна використовувати у Windows напряму, без драйвера J2534. У Linux це інтерфейси [SocketCAN](socketcan.md).

## Підключення

1. Встановіть драйвер пристрою від PEAK. Він приносить бібліотеку `PCANBasic.dll`, яку завантажує Caruspex.
2. На сторінці **Підключитися** виберіть **CAN-інтерфейс**. Кожен канал PCAN із підключеним пристроєм сам з'являється в списку; канали, які вже зайняті іншою програмою, не показуються.
3. Виберіть швидкість (500 кбіт/с для OBD через CAN) і підключіться.

## Що працює

OBD, усі блоки керування через UDS, паралельний пошук блоків, VW TP 2.0 і прослуховування широкомовних значень. CAN FD через PCAN-Basic поки не вбудовано.

## Командний рядок

```
caruspex_cli read --can pcan:USB1@500000
```
