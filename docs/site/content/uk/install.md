# Встановлення

Кожен випуск лежить на [сторінці випусків на GitHub](https://github.com/SenseiIssei/Caruspex/releases/latest). Пакети поки не підписані, тому Windows і macOS один раз перепитають перед першим запуском.

## Windows 10 і 11

| Файл | Що це |
|---|---|
| `Caruspex-<version>-windows-x64-setup.exe` | Інсталятор. Йому не потрібні права адміністратора, він може додати консольну утиліту `caruspex_cli` до шляху пошуку і встановлює середовище WebView2, лише якщо його немає. |
| `Caruspex-<version>-windows-x64.zip` | Портативна версія: розпакуйте і запустіть `caruspex.exe`. |

Під час першого запуску Windows SmartScreen може повідомити, що програма невідома: натисніть "Докладніше", потім "Усе одно запустити".

USB-адаптерам потрібен драйвер для їхнього USB-чипа. Windows 10 і 11 зазвичай знаходять його самі; якщо ні, дивіться [ELM327 через USB](elm327-usb.md).

## macOS 13 і новіші (Apple Silicon)

Завантажте `Caruspex-<version>-macos.dmg`, відкрийте його і перетягніть Caruspex у папку "Програми". Оскільки програма ще не нотаризована, першого разу відкрийте її правим клацанням і пунктом "Відкрити".

## Linux (x86_64)

| Файл | Що це |
|---|---|
| `Caruspex-<version>-linux-x86_64.AppImage` | Працює майже на будь-якому дистрибутиві: зробіть файл виконуваним через `chmod +x` і запустіть. Він також оновлюється сам. |
| `Caruspex-<version>-linux-amd64.deb` | Для Debian і Ubuntu: `sudo apt install ./Caruspex-<version>-linux-amd64.deb` |

Щоб користуватися послідовними адаптерами без `sudo`, один раз додайте себе до групи `dialout`, потім вийдіть із системи і увійдіть знову:

```
sudo usermod -aG dialout $USER
```

## Лише консольна утиліта

Для скриптів і серверів є `caruspex_cli` без інтерфейсу, для Windows, Linux і macOS. `caruspex_cli help` виводить список команд.

## Оновлення

Під час запуску Caruspex питає в GitHub, чи є новіша версія, і більше нічого. Нова версія встановлюється, лише якщо її підпис збігається з ключем, вбудованим у програму. І перевірку, і автоматичне встановлення можна вимкнути в налаштуваннях.

## Менеджери пакетів

Пакети для winget, Homebrew, Flathub і Snap готуються. Поки їх не опубліковано, Caruspex встановлюється з файлів вище.
