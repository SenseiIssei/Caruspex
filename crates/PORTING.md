# Porting Caruspex from C++/Qt to Rust/Tauri

The C++ version (src/, tests/, tools/) stays in the tree as the reference
until the Rust version does everything it does. Port behaviour 1:1: same
protocol bytes, same timeouts, same decoding, same texts, same edge cases.
Do not drop features, comments that explain why, or tests.

## Conventions

- Names: C++ `class FooBar` becomes `struct FooBar` in module `foo_bar`;
  methods and fields in snake_case; enums keep their variant names.
- Errors: `bool f(..., std::string& error)` becomes `fn f(...) -> Result<T, String>`.
  The error text is the same user-facing text as before.
- Texts: `L("de", "en")` becomes `caruspex_i18n::l("de", "en")`,
  `Text{"de", "en"}` becomes `caruspex_i18n::Text::new("de", "en")` (or the
  struct literal). Keep the German and English wording exactly, character for
  character: the other 16 languages are looked up by the English text, so a
  changed English text loses its translations.
- Bytes: `std::string` used as a byte buffer becomes `Vec<u8>` / `&[u8]`.
- Shared traits live in caruspex-link: `Transport` (ELM327 dialogue) and
  `ByteStream` (K-line bytes). Timing helpers: `caruspex_link::timing`.
- Generated tables: the Python generators in tools/ get a Rust output next
  to the C++ one, writing into `crates/<crate>/src/generated/*.rs`
  (checked in, with a "generated by tools/..., do not edit" header).
- Tests: every Catch2 TEST_CASE becomes a Rust test with the same meaning
  (unit tests in the module, larger ones in `crates/<crate>/tests/`). Fakes
  (FakeEcu, FakeEcu2000, fake gateways) are ported too.
- Comments in English, no long dashes (U+2014, U+2013) anywhere, no emojis,
  no mention of tools or assistants used to write the code.
- `#![forbid(unsafe_code)]` where possible; FFI (J2534) keeps unsafe in one module.
- Edition 2024, `cargo clippy -p <crate> -- -D warnings` clean, `cargo fmt`.

## Working in parallel

Each crate has one owner. Only edit files inside your own crate (and your
generator in tools/). Do not edit the root Cargo.toml or other crates; if you
need a new dependency, add it with an explicit version to your crate's
Cargo.toml. Use your own target directory to avoid waiting on build locks:
`CARGO_TARGET_DIR=target/<crate> cargo test -p <crate>`. Do not commit; the
integration commits.
